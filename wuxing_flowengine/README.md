# 五行道境流引擎 (Wuxing Dao-Realm Flow Engine)

基于五行（金木水火土）哲学框架的 AI 研究领域趋势诊断与追踪系统。将 AI 前沿概念映射到五行体系，通过多阶段管道分析认知深度、领域分布和道境演化阶段。

## 核心概念

- **五行映射**：将 AI 概念（如"强化学习""扩散模型""多模态大模型"）映射到木/火/土/金/水五行
- **三层 Spinor 结构**：种子层 (L1) → 现行层 (L2) → 超越层 (L3/L4)，模拟认知深度演化
- **四维道境读数**：O_t（本体稳定性）、E_u（演化不确定性）、C_k（认知耦合度）、K_y（缘位/因果纠缠度）
- **五阶段判定**：生 → 克 → 化 → 通 → 变，诊断领域所处道境阶段
- **双层标注**：同一概念在不同认知层级可具有不同的五行投影

## 快速开始

### 环境要求

- Python 3.10+
- 仅使用标准库（无外部依赖）

### 运行完整月度管道

```bash
cd wuxing_flowengine
python scripts/monthly_pipeline.py --month 2026-08
```

| 阶段 | 说明 | 输出 |

| Phase 1 | 认知深度估算 + 五行映射 + 三层构建 + 道境四维诊断 | `phase1_diagnosis_{month}.json` |

## 存在度 S_p 公式（V1.2 公式结构变更）

### 为什么需要 S_p？

旧乘积公式 `S = O_t × E_u × C_k × K_y × 100` 存在**量纲不可达**问题：四维各自的"最大值"无法同时达到（五行权重互斥约束下，S 理论上限仅 1.47），而 θ_critical = 50~90，导致"化"阶段判定在数学上永远不可达。

### 核心公式

```
S_p = M_p × 100

M_p = [ (O_t^p + E_u^p + C_k^p + K_y^p) / 4 ]^(1/p)
```

S_p 采用**广义平均（Power Mean）**，用一个可调参数 p 统一加性与乘性，解决旧乘积公式的维度不可达问题。

### p 的伦理语义（P忠恕结合）

p 不再是冷冰冰的"均衡敏感度"，而是**"恕度"参数**——它决定了诊断系统对短板的态度：

| p 值 | 恕度标签 | 行为 | 伦理对应 | 适用场景 |
|:---:|:---:|------|------|------|
| 1.0 | 恕之极致 | 短板可被补足 | 纯加性，完全宽恕 | — |
| 0.8 | 宽恕 | 短板显著补足 | 逆境/初学鼓励 | 小石案例、逆境陪伴 |
| **0.5** | **P忠恕中道** | **短板如实呈现但不苛责** | **默认值** | 日常诊断 |
| 0.3 | 严格 | 短板显著拉低 | 自我精进 | 顺境警醒 |
| 0.0 | 均衡（几何） | 短板决定全局 | 严格 | — |
| -1.0 | 苛（调和） | 短板一票否决 | 无恕 | 仅极端场景 |

### S_p 与全局阶段判定的关系

S_p 仅作为**"化"判定的单一输入条件**，不替代全局阶段判定：

```
全局阶段判定优先级链：
  生 → 克（ke_edge_count ≥ 1 触发）→ 化（S_p > θ_critical 触发）→ 通 → 变
```

### P忠恕版 S 卡

诊断报告中的 S 值呈现格式：

```
存在度 S = 39.5（p=0.5 · 恕度中道）
├── 四维：O_t 0.275 / E_u 0.967 / C_k 0.219 / K_y 0.291
├── 最弱：C_k（识位 0.22）——如实看见
├── 最强：E_u（宇位 0.97）——可补足路径
├── 阶段：克（S_p=39.5 < θ_base=50）
└── 恕语：整体未被短板定义，成长空间仍在
```
