# SkillUP 种子培育策略（种·育）提案与落地验证方案 V1.2

> **版本**：V1.2（2026-08-07）
> **V1.2 变更**（来自反者道之动·矛盾迭代引擎自查）：① "性决定"从成才判据降级为**路径一致性审计**（描述性，非预测性）② 引入**失败者/跨界对照**校准判别力（生克并置）③ 定义**五行相似度可计算公式**（余弦）④ **缘四要素 Agent 翻译** ⑤ **双引擎反向回路**（通中生种）⑥ **预期值去伪**（清除方案自身的虚假精确）。

## 一、架构定位：SkillUP 双引擎循环

```
SkillUP 层 · 双引擎循环
├── 种·育（纵向生长）：从 0 到 1 —— 种子发现 → 培育 → 果实
│    对应杨振宁三步法：教学疑难切入 → 科教融合提炼前沿课题 → 师生共创突破
└── 土·通（横向迁移）：从 1 到 N —— 结构提取 → 同态匹配 → 迁移验证
     对应同态映射三步协议（已有）
        ↑___________________________|
        迁移中高频 +2 事件 → 新种子候选（通中生种）

五行闭环：种·育（木生→火化→金克→水变）→ 土·通（土·通）→ 回流（通又生木）
          └──────── 从0到1 ────────┘   └── 从1到N ──┘
```

**一句话定位**：土·通回答"已有技能如何跨域"，种·育回答"新能力如何诞生"——且**迁移中诞生的新兴趣会回流为新种子**，双引擎从流水线升级为生命循环。

## 二、种·育三步协议（Cultivation Protocol · V1.2）

### 2.1 双种子画像

种子画像分为两维——**性决定审计只针对方法种子**：

| 维度 | 定义 | 漂移规则 |
|------|------|---------|
| **题目种子** | what to study——兴趣领域（如：调和分析、数论） | **允许漂移**（课题可换） |
| **方法种子** | how to study——工具偏好（如：解耦、概率视角、o-极小性） | **性决定审计对象** |

### 2.2 三步协议

```
Step 1 - 种子发现（对应：教学疑难切入）
  输入：L2 轨迹中的高价值信号——价值回填标记 +2（关键贡献）的事件
        + 情绪共振信号（"妙"感时刻）
  检测：方法种子出现 ≥3 次独立场景 → "确认种子"
        <3 次 → "待观察"（信度出口）
  输出：双种子画像 {题目种子, 方法种子, 共振强度, 出现频次, 五行向量}

Step 2 - 培育强化（对应：科教融合提炼前沿课题）
  输入：确认种子 + 领域前沿问题库 + 缘四要素（见 2.5）
  动作：方法种子 → 前沿课题的映射 f（同态匹配：保持工具偏好结构，替换题目形式）
  输出：培育计划 {课题, 里程碑, 导师, 环境, 合作者}

Step 3 - 成果验证（对应：师生共创突破）
  输入：培育计划执行轨迹
  验证：成果方法论 vs 方法种子的五行余弦相似度（见 2.3）
  通过 → 晋升 L4 技能 / 固化为个人研究方向
  失败 → 触发"性漂移"标记（方法种子变了）或"缘漂移"标记（环境/课题变了，正常）
```

### 2.3 性决定审计：可计算公式（V1.2 新增）

**定位（V1.2 核心修订）**：性决定不是"成才判据"（不预测成功），而是**"路径一致性审计"**——审计成果是否忠于方法种子，如同宪法审计动作是否越界。**描述性，非预测性。**

**计算公式**：方法种子五行向量 A 与成果方法论五行向量 B 的**余弦相似度**：

```
A = (a木, a火, a土, a金, a水)   // 方法种子五行分布（归一化）
B = (b木, b火, b土, b金, b水)   // 成果方法论五行分布（归一化）

相似度 S_cos = Σ(aᵢ·bᵢ) / (|A|·|B|)

语义：余弦衡量"方向一致性"——方法种子与成果在五行空间中指向是否一致。
（若关注成分重合而非方向，可用加权 Jaccard；V1.2 默认余弦：性决定=方向保持）
```

**阈值**：≥0.7 为"性决定保持"。**校准方式（V1.2 新增）**：0.7 是否合理，须用对照库的分位数校准（见 4.3）——在实测之前，0.7 是"待校准声明"，不是"已验证结论"。

### 2.4 漂移双层检验

| 漂移类型 | 定义 | 判定 | 处置 |
|---------|------|------|------|
| **缘漂移** | 环境/课题/导师变化 | **正常**，不触发警告 | 记录五行变化，不打断培育 |
| **性漂移** | 方法种子变化 | **异常**，触发标记 | 回退 Step 1 重新确认 |

### 2.5 缘四要素：人类尺度 → Agent 翻译（V1.2 新增）

| 缘要素 | 人类尺度（四大师实证） | Agent 翻译（慧惠） |
|--------|----------------------|-------------------|
| **导师** | Guth / Eliashberg / Sarnak | Base 层知识资产 + 元治理规则（"AI 结构化 + 人类体证"） |
| **环境** | IAS / 普林斯顿 / 哈佛 | 情境指针 L1b（当前情境上下文，BVS V1.1） |
| **课题** | 百年难题群（挂谷/希尔伯特六/格罗莫夫-维滕/安德烈-奥特） | 前沿问题库（知识树待解问题/领域 open problems） |
| **合作者** | Zahl（王虹） | §5.4 跨域同态候选队列（协同 Agent/外部工具） |

### 2.6 双引擎反向回路：通中生种（V1.2 新增）

```
种·育 → 土·通：果实跨域迁移（已有）
土·通 → 种·育：迁移过程中若出现新的高价值兴趣信号
        （价值回填 +2 事件 ≥3 次，且不属于现有方法种子）
        → 回流为新种子候选，进入 Step 1
```

**意义**：双引擎从"单向流水线"升级为"生命循环"——与五行流转闭环一致（通又生木）。这符合四大师的后期路径：跨界（王虹从 Fourier 限制到挂谷）本身就会催生新方法种子。

## 三、与既有机制的三重对接

### 3.1 与五行流转：五行引擎完整闭环

| 五行 | 流转动作 | 种·育对应 |
|------|---------|----------|
| 木 | 生（积累） | 种子发现（兴趣萌芽） |
| 火 | 化（整合） | 培育强化（方法×前沿融合） |
| 金 | 克（淘汰） | 成果验证（性漂移证伪） |
| 水 | 变（更新） | 情境适应（方法在不同题目下现行） |
| 土 | 通（迁移） | 土·通（成果扩散） |
| 通→木 | 回流 | 通中生种（迁移催生新种子） |

### 3.2 与 BVS 记忆架构：跨域闭环的纵向孪生 + 回流挂载

| 记忆层 | 种·育使用方式 |
|--------|--------------|
| L2 轨迹 | 价值回填 +2 事件 = 种子信号源（也用于通中生种的回流检测） |
| L3 策略 | 方法种子→课题映射 = 培育策略 |
| L4 技能 | 性决定审计通过 = 技能晋升 |

### 3.3 性决定审计与宪法审计的同构

性决定审计（成果是否忠于方法种子）与慧惠宪法审计（动作是否越界）是**同一模式**：REJECT 优先于生成，越界即中断。**性决定是种·育的良知，不是预言。**

## 四、落地验证方案（Phase 0-4 · V1.2 修订）

### 4.1 验证目标

证明"种·育三步协议"能从兴趣信号中培育出可执行的能力与成果，且成果保持方法种子本性——**并（V1.2 新增）用失败者/跨界对照校准性决定审计的判别力**。

### 4.2 实验对象：双种子试点

| 种子 | 来源 | 方法种子 | 培育目标 |
|------|------|---------|---------|
| 种子A：跨域迁移方法论 | 同态映射引擎（五轮对话复盘） | 同态映射三步协议 | "跨域诊断咨询技能" |
| 种子B：语言谱系×五行诊断 | 语言树概念地图+诊断 | 五行诊断七维指标 | "跨学科分析技能" |

### 4.3 五阶段设计

**Phase 0：种子信号采集（1-2 周）**
- 回溯提取高价值事件与共振信号
- 输出：5-8 个候选双种子画像（含五行向量）
- **成功标准**：候选 ≥5 个

**Phase 1：种子确认——"已知答案"回溯验证（1 周）**
- 标尺一：妙秒真实 taste（道德经/五行/莫比乌斯环）
- 标尺二：四大师方法种子（解耦/概率/严格化/o-极小性）
- **成功标准**：检出率 ≥80%（**V1.2：待实测，未预设预期值**）；画像相似度 ≥0.7

**Phase 1.5（V1.2 新增）：性决定判别力测试——生克对照**
- **正样本**：四大师（性决定保持 4/4）
- **负样本**：跨界成功者 ≥3 人（性漂移但成功：如物理转生物、数学转金融、纯数转应用）
- 检验：余弦相似度能否区分两组？（理想：正样本 ≥0.7，负样本 <0.7）
- **成功标准**：两组相似度分布显著分离（区间不重叠或重叠 <20%）
- **意义**：这是"克"进场——只有负样本可区分时，性决定才从"成功者自画像"升级为"有判别力的审计"

**Phase 2：培育实验——前瞻验证（4-6 周，技能尺度）**
- 培育计划含缘四要素（Agent 翻译版）
- **成功标准**：兴趣保持度 ≥0.7 + 产出 ≥2 个可交付成果

**Phase 3：性决定审计——结构验证（1 周）**
- 方法种子五行 vs 成果方法论五行的**余弦相似度**（公式见 2.3）
- **成功标准**：相似度 ≥0.7（阈值以 Phase 1.5 校准结果为准）

**Phase 4：生态衔接——土·通对照实验 + 反向回路检测（2 周）**
- 种·育产出技能 vs 随机技能送入土·通迁移
- 同时检测迁移过程中的 +2 事件，验证"通中生种"回流
- **成功标准**：迁移成功率比（**V1.2：待对照实验确定，不预设 1.5 倍**）；回流新种子候选 ≥1 个

### 4.4 指标汇总表（V1.2 更新）

| Phase | 指标 | 数据来源 | 成功标准 | 状态 |
|-------|------|---------|---------|------|

### 4.5 风险与降级方案（V1.2 更新）

| 风险 | 降级方案 |
|------|---------|
| **幸存者偏差（V1.2 新增）** | 结论只称"路径一致性描述"，不称"成才判据"；判别力以 Phase 1.5 为准 |
| 负样本（跨界成功者）难找 | 放宽为"领域内转方向成功者"（如解析数论转算术几何），标注样本异质性 |

| 样本 n=2 不足 | 声明"双种子试点"，结论标注低信度，验证性结论待 n≥5 |

## 六、总结

> **种·育与土·通构成 SkillUP 双引擎循环：一纵一横、一生一通、通又生木——种·育从方法种子培育出能力果实（杨振宁三步法 + 四大师实证），土·通让果实扩散到新域，迁移中的新兴趣回流为新种子；V1.2 在自查中完成六处进化：性决定从"成才判据"降级为"路径一致性审计"（描述而非预言）、失败者/跨界对照进场（生克并置，判别力才成立）、余弦公式让 ≥0.7 可计算、缘四要素完成 Agent 翻译、通中生种让双引擎成为生命循环、预期值去伪让方案践行自己的信条。四大师证明协议能描述成功（生），跨界对照将证明协议能区分成败（克）——生克并置，性决定审计才算完成它的定义：不是预言谁是天才，而是审计成果是否忠于种子，正如宪法审计动作是否越界——不假装精确，不自封判据，只做良知。**
