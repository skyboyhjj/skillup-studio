## 第一章 项目概述

### 1.1 背景

[五行诊断与道境坐标系_融合设计方案 V1.2](五行诊断与道境坐标系_融合设计方案_v1.2.md) 建立了从概念地图到道境四维读数的完整计算框架，但存在以下待验证问题（§9.3）：

- **S 公式理论上限远低于 θ_critical**：乘积 S 最大仅 1.47，而临界阈值可达 90~180，需验证是否需要切换到轨道 B/C
- **跨领域 S 值不可比**：不同领域（经典文本 vs 儿童成长 vs 管理实践）的 S 绝对值天然不可比，需建立领域基准
- **Kᵧ 负值问题**：恶性因果循环的量化尚未实现
- **三+一轨并行验证**：轨道 A（乘积 S）、轨道 B（S_spiral）、轨道 C（S_v2）、轨道 D（模长 S）需在同一数据上对比

BAAI 智源社区「知识树」提供了 **323 个节点、15 个领域、每月 15 份科研报告** 的结构化数据，为上述验证提供了理想的数据源。

### 1.2 项目目标

| 目标 | 描述 | 优先级 |
|------|------|--------|
| **数据采集** | 自动化采集知识树节点数据、边关系、月度报告 | P0 |
| **五行映射** | 建立 AI 领域 → 五行的映射规则，对 314 个三级节点逐项分类 | P0 |
| **静态诊断** | 对当前知识树快照运行道境五行引擎，产出四维读数 + 阶段判定 | P0 |
| **动态诊断** | 采集 3~6 个月月度报告数据，构建时间序列，验证动态模式判定 | P1 |
| **三+一轨对比** | 对同一数据同时跑 A/B/C/D 四条轨道，对比输出一致性 | P1 |
| **θ_critical 校准** | 建立 AI 领域的基准临界阈值 | P2 |
| **领域画像库** | 为 15 个 AI 子领域建立五行画像，丰富附录 A 画像库 | P2 |

### 1.3 核心设计原则

1. **真实数据驱动**：所有计算基于实际采集的知识树数据，不做人工模拟
2. **可复现**：采集脚本可重复运行，月度数据可追溯
3. **与 V1.2 方案对齐**：输入输出格式兼容 V1.2 的 `diagnose_dao_realm()` 接口
4. **渐进验证**：先静态后动态，先单轨后三轨，逐步推进

### 4.2.1 关键节点双层标注（旋量-太极修正）

**修正动机**：旋量-太极模型认为一个实体的五行不是唯一的，而是取决于它在旋量中所处的相位。同一节点在不同层级上可以有不同的五行投影——固定标签会丢失旋量的相位信息。

**示例**：以"强化学习"为例，其在三层中的五行投影不同：
- 种子层：**金**——精炼的数学框架
- 现行层：**火**——驱动智能体行动的核心机制
- 超越层：**木**——与神经科学交汇正在开辟新方向

**适用范围**（314 个节点中需要双层标注的比例估算）：

| 节点类型 | 占比 | 处理方式 |
|---------|------|----------|
| 纯技术性节点（"卷积神经网络CNN"等） | ~50% | 单标签足够 |
| 跨领域节点（"强化学习"、"世界模型"等） | ~20% | 需双层标注 |
| 混合型节点（"人机协作"、"社会模拟"等） | ~30% | 视上下文定 |

```python
# 旋量节点——在不同层级上可以有不同五行标签
# 这不是"前后不一致"，而是旋量在不同相位下的不同投影

class SpinorNode:
    """旋量节点：跨层级时五行标签可不同"""

    def __init__(self, name: str):
        self.name = name
        self.wuxing_projections = {
            "seed": None,       # 在种子层的相位
            "current": None,    # 在现行层的相位
            "transcend": None,  # 在超越层的相位
        }

    @property
    def is_dual_label(self) -> bool:
        """是否在不同层有不同标签（即是否为歧义节点）"""
        projections = self.wuxing_projections.values()
        unique = set(p for p in projections if p is not None)
        return len(unique) > 1

    def get_wuxing_for_layer(self, layer: str) -> str:
        """获取指定层的五行标签"""
        return self.wuxing_projections.get(layer, "土")
```

**预估工作量**：约 60-90 个节点需要额外标注，每个节点额外标注 1-2 层，总计约 100-150 次标注，额外耗时约 0.5 天。

### 4.3 三层结构构建（独立三层模型 · 修正）

**修正说明**：审查报告指出，原方案将知识树的 Level-1→种子、Level-2→现行、Level-3→超越 存在根本性错误——知识树的 Level-3（最具体的实现技术，如"卷积神经网络CNN"、"数据增强"）在认知抽象层次上与概念地图的"超越层"（最高抽象级别的愿景与范式）处于**相反的两端**。故修正为**独立三层模型**：不以知识树层级直接对应，而是以认知深度为分配依据。

```python
class LayerBuilder:
    """
    独立三层模型：按认知深度（而非知识树层级）构建种子/现行/超越。
    原方案: Level-1→种子(2)  Level-2→现行(15)  Level-3→超越(314)
    修正后: 认知深度 L1→种子(~20-30)  L2→现行(~150-200)  L3/L4→超越(~50-80)
    """
```

## 第五章 道境诊断计算层

### 5.1 计算流程

```
标准化节点 + 五行分类
        │
        ▼
  [步骤1] 估算认知深度 + 构建三层结构
        │  · 每个节点估算认知深度 L1-L4（关键词匹配 + Level 辅助）
        │  · 种子层 = 认知深度 L1 的节点（~20-30 个）
        │  · 现行层 = 认知深度 L2 的节点（~150-200 个）
        │  · 超越层 = 认知深度 L3/L4 的节点（~50-80 个）
        │  · 关键歧义节点执行双层标注（见 §4.2.1）
        │
        ▼
  [步骤2] 五行诊断器 v2 运行
        │  · 七维指标体系（维度一~维度八）
        │  · 频次分布、层×五行矩阵、重心偏移路径、熵、重心向量、画像、判语、认知深度
        │
        ▼
  [步骤3] 五行→四维映射（v1.0_initial 系数）
        │  · Oₜ = w_土×0.6 + w_金×0.3 + (1−H/H_max)×0.1
        │  · Eᵤ = 1 − 0.5×|w_木−0.25| − 0.5×|w_水−0.25| − 0.3×√(cx²+cy²)
        │  · Cₖ = w_水×0.5 + w_火×0.3 + w_木×0.2
        │  · Kᵧ = w_火×0.4 + w_土×0.3 + ke_edge_count/2×0.3
        │
        ▼
  [步骤4] 三+一轨 S 计算
        │  · 轨道 A: S = Oₜ×Eᵤ×Cₖ×Kᵧ×100
        │  · 轨道 B: S_spiral = Σ(每层加权得分 × 层间转换效率)
        │  · 轨道 C: S_v2 = phase × gradient × accumulation
        │  · 轨道 D: S_D = √(Oₜ²+Eᵤ²+Cₖ²+Kᵧ²)（探索性模长 S）
        │
        ▼
  [步骤5] 阶段判定
        │  · 静态模式: 生/克/化/通/变
        │  · 动态模式: ΔH + 重心位移 + 深度突变
        │
        ▼
  输出：道境五行诊断报告
```

### 6.3 验证 3：S 公式上限

```
输入：15 个领域 × 各自的四维读数
输出：S 值分布表（含轨道 D）

关键问题：
- 是否所有领域 S < 1.47？（乘积 S 理论上限）
- 轨道 D（模长 S）理论上限 ~1.8，是否同样远低于 θ_critical？
- 若乘积 S 和模长 S 均远低于 θ_critical（~90），则轨道 A/D 不适合与 θ_critical 对标
- 验证轨道 B/C 的 S 值是否与 θ_critical 同量纲

决策标准：
- 若轨道 A 的 S 始终 < 2，而 θ_critical ≥ 60 → 确认轨道 A 不能对标 θ_critical
- 若轨道 D 的 S 在 1.0~1.8 范围 → 确认轨道 D 天然适合横向比较，但不对标 θ_critical
- 若轨道 B 或 C 的 S 在 10~100 范围，且与 θ_critical 可比 → 推荐切换
```

### A.3 边界情况处理

| 边界情况 | 处理方式 |
|----------|----------|
| 跨领域节点（如"多模态大模型在机器人领域应用"） | 按主导关键词匹配，归属第一个匹配到的五行 |
| 歧义节点（如"强化学习"、"世界模型"、"人机协作"） | 启用双层标注（见 §4.2.1），在不同层分配不同五行标签 |
| 模糊节点（如"其他AI领域"） | 归入所属 Level-2 的五行 |
| 重复节点（如"模仿学习"在具身智能和 ML 基础中均出现） | 按实际所属 Level-2 分别归类 |
| 新增节点（不在预定义关键词库中） | 人工审核后加入关键词库 |
