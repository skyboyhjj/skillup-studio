1. **本地 arXiv 树文件为简化版**（7 节点：缺 cs.NE/cs.HC/cs.IR/cs.MM；08 月 cs.AI=1400 < cs.LG=3400，与壳核报告"火反超"的生产数据不同）——**数值口径须以生产侧完整数据复核**

   ```
   python engine_adapter_v2.py --dir <树文件目录>
   ```
3. **BAAI 05/06/07 三个月** → 种子=05、现行=06、超越=07（时间演化模式）；**GitHub/HF 两个月** → 种子=06、现行=07、超越=07 镜像（无演化边，C_k 天然为 0——标注"月数不足"）
