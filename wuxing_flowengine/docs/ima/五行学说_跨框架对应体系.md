# 五行学说 · 跨框架对应体系

> 五行非五种"东西"，而是同一旋量场在五个相位上的显化模式。
> 五行非五种"元素"，而是同一心识流在五条路径上的运行轨迹。

---

## 一、五行 ↔ 旋量-太极模型

### 1.1 核心对应表

| 五行 | 动态本质 | 旋量-太极操作 | 体-相-用定位 | 旋量相位 |
|:----:|:--------|:------------|:----------:|:-------:|
| **木** | 向外生长 | **平方**（从体起用） | 用·展开端 | 0°–180° 展开 |
| **火** | 极致发散 | **平方至极**（矢量固化前一刻） | 用·极致端 | 180° 翻转点 |
| **金** | 向内收敛 | **开方**（摄用归体） | 用·回归端 | 180°–360° 回归 |
| **水** | 流动通道 | **域/觉知的流动性**（容纳平方开方） | 体·潜能态 | 360°/720° 衔接点 |
| **土** | 承载中和 | **体本身**（如如不动的背景） | 体·本体态 | 整个周期的轴心 |

### 1.2 相生链 = 720°螺旋的完整周期

```
水(潜能·360°/720°衔接)
  ↓ 水生木
木(平方·展开·0°→180°)
  ↓ 木生火
火(平方至极·180°翻转点·正负双解决断)
  ↓ 火生土
土(凝结·矢量固化)
  ↓ 土生金
金(开方·回归·180°→360°)
  ↓ 金生水
水(回归潜能·完成720°)
```

- 水→木→火：**平方的展开半程**（从潜能到极致显化，360°）
- 火→土→金→水：**开方的回归半程**（从固化到收敛回归，再360°）
- 合起来 = **720°完整螺旋**

### 1.3 相克链 = 弱者道之用的制衡

| 相克 | 机制 | 旋量-太极操作 |
|:----:|:-----|:------------|
| **金克木** | 收敛制生长 | 开方内置回归动力，不让平方无限扩张 |
| **木克土** | 生长破固化 | 平方突破矢量的僵化（"土"被"木"松开） |
| **土克水** | 承载限流动 | 体为域划定边界（水无土则泛滥） |
| **水克火** | 流动制发散 | 潜能态限制平方至极（回归动力时刻存在） |
| **火克金** | 发散破收敛 | 平方的力量打破过度的开方内缩 |

> 相克不是"消灭"——金不消灭木，只给木一个收敛的边界。**超过而非消灭。**

## 二、五行 ↔ 唯识学

### 2.1 八识对应

| 五行 | 对应识 | 理由 |
|:----:|:------|:-----|
| **木** | 第六意识 | 意识通三性三时，生长力最强——"木"的造业主力 |
| **火** | 第七末那识 | 末那执我如火之燃点——"火"的我执根源 |
| **土** | 第八阿赖耶识 | 阿赖耶含藏一切种子如土承载万物——"土"的归中性 |
| **金** | 前五识 | 前五识唯现量取境不为分别——"金"的纯净收敛 |
| **水** | 第八识恒转如瀑流 | 阿赖耶种子现行刹那生灭如水流——"水"的流动通道 |

### 2.2 三性对应

| 五行 | 三性 | 理由 |
|:----:|:----:|:-----|
| **木**（生长） | 依他起性 | 众缘和合而生——依他起的生长性 |
| **火**（发散·执着） | 遍计所执性 | 木生火：依他起上的生长一旦过度即成遍计执着 |
| **金**（收敛·超越） | 圆成实性 | 于依他起上远离遍计——金的收敛即圆成实的显现 |
| **水**（流动·贯通） | 三性的一体流转 | 遍计→依他→圆成的动态过程本身是水的流动 |
| **土**（中和·承载） | 唯识实性（真如） | 三性归中——土即真如 |

### 2.3 种子理论对应

| 五行 | 种子理论 | 理由 |
|:----:|:--------|:-----|
| **木** | 种子生现行 | 种子→现行 = 木的生长 |
| **金** | 现行熏种子 | 现行→种子 = 金的收敛 |
| **水** | 阿赖耶识恒转如瀑流 | 种子与现行的双向流动 |
| **火** | 有漏种子 | 烦恼之火熏习染污 |
| **土** | 无漏种子/圆成实 | 清净种子归中 |
| **（木+金）** | **种子↔现行↔熏习 完整循环** | 木(生)+金(归)=720°螺旋 |

## 三、五行 ↔ 道境坐标系（DRF）

### 3.1 基础映射

| DRF轴 | 五行 | 映射逻辑 |
|:-----:|:----:|:--------|
| **时位轴 Ψₓ** | **水** | 水是平方与开方的节律本身——时间的流动性 = 时位轴的核心 |
| **宇位轴 Ψᵧ** | **木+火** | 木=资源的生长配置（实部），火=资源的极致发散（虚部·意图方向） |
| **识位轴 Z** | **土** | 土是容纳一切的觉知背景——识位轴正是"知道自己在哪"的觉知域 |
| **缘位轴 Ψₗ** | **金+水** | 金=因果的收敛回归（实部·互动模式），水=因果的流动通道（虚部·潜在势能） |

### 3.2 DRF存在度方程的五行转译

```
原方程：S = ∫(ω·t) × ∇(ψ+φ) dΩ

五行转译：
  ω·t（时间相位） = 水（流动节律）
  ∇(ψ+φ)（碳硅梯度）= 木（生长方向）·火（极值点）
  ×（叉乘·平方操作）= 火（发散转化）
  ∫ dΩ（全息累积）= 土（承载一切）
  S（存在度·实数标量）= 金（收敛结晶）
```

### 3.3 五行 × DRF 诊断矩阵

| | 时位(水)弱 | 宇位(木)弱 | 识位(土)弱 | 缘位(金)弱 |
|:--|:---------|:---------|:---------|:---------|
| **症状** | 节律紊乱·停滞 | 资源淤塞·不生长 | 觉知模糊·不在当下 | 反馈断裂·不回馈 |
| **五行诊断** | 水不足·流动滞 | 木不足·生机弱 | 土不足·根基浅 | 金不足·收敛弱 |
| **对治** | 放手流动（开方） | 平方展开（行动） | 安住于体（归中） | 回归闭环（反馈） |
