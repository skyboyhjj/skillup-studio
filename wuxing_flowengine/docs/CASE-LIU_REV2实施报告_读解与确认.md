## 四、⚠️ 两处需澄清

### 1. 五行术语："金生土（反生）"表述不准确

五行相生：木→火→土→金→水→木。**金生的是水，土生的是金**——"金→土"不是"金生土"，而是"土生金"的**逆方向**（或"非相生方向"）。报告写"金生土（反生）"不符合相生规则。

**建议修正**：`金→土（土生金之逆，非相生方向）`——同理"金→土保持度 0.72 偏低"的归因应表述为"逆生方向需额外转化"。

### 2. 测试断言粒度模糊 + 阈值紧贴

```
test_chain_segment_retention："每段保持度在预期 ±0.08 内" → PASS
单条映射实际：-0.13（抽象→缘起）、-0.27（缘起→模式）——若断言单条则 FAIL
段平均实际：-0.0133 / -0.0533 —— 均在 ±0.08 内 → 断言段平均才 PASS
test_chain_vs_direct_delta：偏差 ≤0.16 → PASS（实际 0.1512，margin 仅 0.0088）
```

**需确认**：①"每段保持度"是段平均还是单条？（若单条，-0.27 超限应 FAIL）②0.16 阈值依据？（紧贴 0.1512，建议放宽至 0.20 或说明来源）
