## 三、核心发现：结构-活跃度"剪刀差"

### 3.1 大语言模型领域对比

| 五行 | 节点占比 | 论文占比 | 差异 | 方向 |
|:----:|:-------:|:-------:|:----:|:----:|
| 木 | 0.0% | 10.0% | **+10.0%** | ↑ 生成/具身方向论文活跃，但知识树无节点 |
| 火 | 0.0% | 13.3% | **+13.3%** | ↑ 智能体/协作方向论文活跃，但知识树无节点 |
| 土 | 7.1% | 26.7% | **+19.5%** | ↑ 架构/训练方向论文远超节点占比 |
| 金 | 35.7% | 3.3% | **-32.4%** | ↓ 安全/伦理方向节点多但论文极少 |
| 水 | 57.1% | 46.7% | -10.5% | ↓ 水仍主导但占比下降 |

### 3.2 重心漂移

```
节点重心: (0.3571, 0.5714) → 金+水象限（精炼探索）
论文重心: (-0.0667, 0.3333) → 木+火+水象限（生长传播）
漂移向量: (-0.4238, -0.2381)  幅度: 0.4861
```

**判读：显著漂移** —— 研究方向正在从"金+水"（精炼的深层探索）向"木+火+土"（生成、传播、架构基础设施）方向偏移。知识树结构尚未反映这一趋势。

### 3.3 剪刀差解读

- **知识树说**：大语言模型领域是"金+水"主导（推理逻辑 + 深层理解）
- **论文说**：当前研究热点是"土+水+火"（架构优化 + 智能体 + 推理）
- **剪刀差根源**：知识树节点分类偏重"大语言模型"整体语义（水），但论文级细粒度分类揭示了内部的多元化

## 五、θ_critical 校准

### 5.1 校准公式

```
活跃-失衡指标 = 论文流量(千篇/月) × (1 - S_D)
```

| 参数 | 大语言模型 | 说明 |
|------|:---------:|------|
| 论文流量 | 5.9k 篇/月 | 6月提交量 |
| S_D | 0.8315 | 四维均衡度（Phase 2） |
| 失衡度 (1-S_D) | 0.1685 | 五行偏斜程度 |
| **活跃-失衡指标** | **0.99** | 接近阈值 1.0 |

### 5.2 判读

- 大语言模型 **0.99**，接近但未超过 1.0 阈值
- 如果 5月数据（7.9k 篇）代入 → 7.9 × 0.1685 = **1.33**，超过阈值
- **结论**：大语言模型在 5月处于失衡区，6月回落到临界附近。这与 Phase 2 全局"化"判定一致——知识体系正在经历范式转换期。
