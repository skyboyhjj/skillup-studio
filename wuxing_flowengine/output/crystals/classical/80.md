# 第80章

**标题**: ：小国寡民——全书社会理想

## 原文

> 小国寡民。使有什伯之器而不用，使民重死而不远徙。虽有舟舆，无所乘之；虽有甲兵，无所陈之。使民复结绳而用之。甘其食，美其服，安其居，乐其俗。邻国相望，鸡犬之声相闻，民至老死不相往来。

## 五步读解


### 一、文本细读（原文 + 版本校勘 + 字词溯源 + 句读辨析）

**原文：**
> 小国寡民。使有什伯之器而不用，使民重死而不远徙。虽有舟舆，无所乘之；虽有甲兵，无所陈之。使民复结绳而用之。甘其食，美其服，安其居，乐其俗。邻国相望，鸡犬之声相闻，民至老死不相往来。

**版本校勘：** 帛书甲本开篇作"小邦寡民"，乙本作"小国寡民"，"邦"避汉高祖刘邦讳改"国"，语义无别。"什伯之器"帛书本作"十百人之器"，河上公本作"什佰之器"，王弼本从"什伯"，既指兵器之锐利，亦暗喻管理工具之繁复。"使民复结绳而用之"中"复"字为关键，帛书甲本作"使民复结绳而用之"，乙本"复"字残损，然诸本皆存"复"义，强调"回归"而非"倒退"。

**字词溯源：**

1. **什伯（shí bǎi）**——甲骨文"什"从人从十，本义十人编伍；"伯"从人从白，本义百人之长。此处或指"什佰之器"（以一敌十百的精良兵器），或指"什佰之制"（严密的军事编制）。"而不用"三字是本章第一重转折——拥有而不依赖，存在而不启用。

2. **结绳（jié shéng）**——《周易·系辞下》："上古结绳而治，后世圣人易之以书契。"结绳是文字发明前的记事方式。"复结绳而用之"以"复"（返回、回归）为灵魂，呼应第16章"夫物芸芸，各复归其根"、第28章"复归于朴"——这不是历史倒退，而是本体论意义上的"归根复命"。

3. **甘/美/安/乐**——四字皆为意动用法（以……为甘/美/安/乐），表达主观的满足感、欣悦感。主语省略，施动者是"民"自身，强调内发性而非外在赋予。此四字连缀构成全章最明亮的意象群，是老子为其社会理想描绘的幸福感光谱。

**句读辨析：** 本章节奏在全书中极为特殊——以短句为主，多四字结构，间以五言，"虽有……无所……"两联对仗工稳，"甘其食……乐其俗"四句排比递进，至末句长句收束。这种语体刻意营造一种舒缓、从容、不迫的呼吸感，与所描述的理想生活节奏同构。

### 二、语境建构（历史语境 + 文本内证 + 思想脉络）

**历史语境：** 本章成于战国中晚期（约前4—前3世纪），正值列国兼并愈演愈烈之际。诸侯"争地以战，杀人盈野；争城以战，杀人盈城"（《孟子》），人口被全面动员为战争资源与徭役劳力。"什伯之器"即当时先进的弓弩、连发机括等军用器械；"远徙"是无数流民被战争驱赶离乡的真实写照。老子的小国理想，正是对这个苦难时代的镜像翻转——战国的每一分残酷，都被翻转为理想国的每一缕安宁。

**文本内证（2-3条）：**

- **第57章"以无事取天下"**："天下多忌讳而民弥贫，民多利器国家滋昏，人多伎巧奇物滋起，法令滋彰盗贼多有。"与第80章"有什伯之器而不用""使民复结绳而用之"形成政治哲学层面的严密对应——技术越发达，治理反而越失效。
- **第46章"却走马以粪"**："天下有道，却走马以粪；天下无道，戎马生于郊。"第80章"虽有甲兵无所陈之"正是"天下有道"的意象展开。
- **第80章自身内部**：从"什伯之器""舟舆""甲兵"到"结绳而用"形成"器具→交通→军事→文化"四层还原，从文明最外缘一路退回到最内核——人的生存本身。

**思想脉络：** 第80章处于全书政治哲学的终结点。老子从个体修养（第8章"上善若水"）到治国方略（第57章"以正治国"、第60章"治大国若烹小鲜"），最终在第80章呈现完整的社会理想图景。这一章是"无为"原则在社会层面的终极投射——不是无政府主义，而是"政府最小化、生活最大化"的政治诗学。

### 三、争议辨析（1-2争议 + 三家解读 + 最优解判定）

**争议一："小国寡民"是历史倒退还是精神隐喻？**

- **王弼注**："国既小，民又寡，尚可使反古，况国大民众乎？"王弼将此章解为"反古"（回归上古淳朴），但不认为这是现实政治方案，而是"言无事"之治的极致描述。
- **河上公注**："圣人虽治大国，犹以为小，示俭约，不为奢泰。"将"小"和"寡"读为圣人的主观态度——不是真的让国家变小，而是以此心态治国。
- **现代学者**（如陈鼓应）：主张双重解读——表层书写上古乌托邦意象，深层批判文明异化。"小国寡民"与卢梭"回归自然"、梭罗"瓦尔登湖"异曲同工。

**最优解判定：** 当采"隐喻优先、字面并存"的解读策略。"小国寡民"不能简单判为历史倒退，因为"复"在老子体系中特指"归根复命"的本体论运动——回到"道"本身，而非回到某个历史阶段。同时，乌托邦书写在先秦并非孤例，《庄子·胠箧》"至德之世"与《礼记·礼运》"大同"皆为同类理想。第80章的价值不在提供施政蓝图，而在确立一个关于"好生活"的批判性参照系。

**争议二："民至老死不相往来"——封闭自守还是自足无求？**

- 批评者（如梁启超早期）认为此乃"消极退缩"的封闭思想。
- **合理读法**：上文言"甘食美服安居乐俗"，已说明人民的生活需求在本社区内得到充分满足。"不相往来"不是敌意隔绝，而是"不需要往来"——自足状态的自然结果。此与第46章"知足之足常足矣"形成互文。

### 五、意义转化（古今贯通 + 3条实践路径）

**古今贯通：** 第80章在21世纪呈现出惊人的"逆行相关性"——在全球化、城市化、数字化狂飙突进的时代，"小国寡民"成为对速度的减速阀、对膨胀的收缩剂。它不是让我们真的回到结绳时代，而是追问：我们究竟需要多少"什伯之器"才能幸福？

**3条实践路径：**

1. **消费极简：** "甘其食，美其服"教我们在既有条件下发现满足，而非在无限升级中追逐满足。实践"够用即美"的生活美学。
2. **社区深耕：** "不远徙""不相往来"启发在地化生活——在本社区解决大部分生活需求，重建邻里信任与地方感。
3. **技术节制：** "有什伯之器而不用"不是反技术，而是保持"可不用"的自由——不被工具反向驯化。
