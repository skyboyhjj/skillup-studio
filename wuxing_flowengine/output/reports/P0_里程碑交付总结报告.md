## 3. 回归结论

### 3.1 确认的结论

1. **"同一存在度"升级为真信号**：v2 真实引擎下壳核 S_p 收敛维持（绝对差 0.97 < 5 点），非 fallback 伪影
2. **"不同画像"方向一致**：水（+17.7pp）、土（-11.2pp）、火（-7.1pp）的壳核差异在 v2 和 fallback 中方向完全一致
3. **壳核互补框架成立**：壳的规划主导（水 30.6%）vs 核的产出主导（土 27.5%），在真实引擎下保持稳定
4. **四层生态梯度清晰**：S_p 壳核（7.5-8.5）→ 工程/模型层（14.2-14.8）翻倍，E_u 从多样性（0.03）→ 集中性（0.38）递增

### 3.2 Fallback 三大问题解决状态

| 问题 | 状态 | 说明 |
|------|:----:|------|
| C_k ≡ O_t 共线 | ✅ 解除 | v2 全部 C_k=0.0，独立于 O_t |
| K_y = 1.0 零区分 | ✅ 恢复 | 全部 < 1.0（0.0346-0.2079） |
| E_u 低值 | ⚠️ 部分解决 | 低 E_u=均匀多样是真特征，非伪影；dim4/dim5 补充 |

### 3.3 C_k=0 的精确语义

当前所有四源 C_k=0，但语义从"无演化数据"升级为 **"有主导行演化，但演化无生克关系"**：
- BAAI 木→水：非生非克（水→木才是相生）
- arXiv 土→火：非生非克（火→土才是相生）
- 引擎正确不生成边——这是有效信息，非缺陷

## 4. 关键技术决策

| 决策 | 内容 | 依据 |
|------|------|------|
| 引擎纯净原则 | 不改 v2 源码，适配层独立实现 | 降低耦合，便于 v2 独立升级 |
| 时间演化模式（方案 A） | 最早月→种子层、中间月→现行层、最近月→超越层 | 保留"LLM 爆发前均衡态"信息 |
| 空月回退 | 自动跳过 n_nodes=0 的月份 | 避免 BAAI 08 空月导致超越层伪影 |
| weight 加权展开 | concepts 展开使 v2 统计等价于 weight 加权 | 解决 v2 等权计数缺陷 |
| 收敛判定以绝对差为准 | 绝对差 < 5 点即判定收敛（既有约定） | 相对差因 v2 量纲下移（S_p 32→8，分母缩小 4x）被放大，作为稳健性参考并报 |
| 双口径并报 | 绝对差 + 相对差同时报告 | 透明度，不假装精确 |
