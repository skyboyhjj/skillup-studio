## 一、方法论

### 1.1 两层级架构
- **节点层 (静态结构)**: 知识树L3节点按领域-五行分类，代表知识体系的**结构分布**
- **论文层 (动态活跃度)**: 6月报代表性论文按关键词五行分类，代表研究前沿的**活跃方向**

### 1.2 核心指标
| 指标 | 定义 | 含义 |
|------|------|------|
| 结构-活跃度差异 | 论文五行% - 节点五行% | >+5%: 活跃度超前; <-5%: 活跃度滞后 |
| 重心漂移幅度 | sqrt(Δx² + Δy²) | >0.3: 显著漂移; 0.1-0.3: 轻度; <0.1: 几乎无漂移 |
| θ_critical | 论文流量(千篇) × (1 - S_D) | >1.0: 失衡预警 |

## 三、各领域结构-活跃度对比详解

### 3.1 交叉领域智能应用 (漂移 0.9089, 排名第1)
- 节点: 火(87.5%) 绝对主导; 论文: 火→23.3%, 土→33.3%, 水→26.7%
- **解读**: 知识树以"应用"为中心，但论文已向**基础设施(土)和基础研究(水)** 扩散，AI+科学/医疗/教育等交叉领域正从应用层向方法层深化

### 3.2 计算机视觉 (漂移 0.8818, 排名第2)
- 节点: 水(90.9%) 绝对主导; 论文: 木→63.3%, 水→16.7%
- **解读**: 从传统识别/检测(水)向**生成式视觉(木)** 剧烈偏移——扩散模型、3D生成、NeRF/Gaussian Splatting 主导了CV前沿
- θ_critical = 1.20 ⚠️ **已进入失衡区**

### 3.3 智能体 (漂移 0.8090, 排名第3)
- 节点: 木(48.4%)+火(22.6%); 论文: 火→79.3%, 木→3.4%
- **解读**: 知识树重"具身/Action"，但论文集中在**多智能体协作、评估基准、工具使用**等火行方向，体现了从单体智能向群体智能的范式迁移

### 3.4 安全、可信与伦理 (漂移 0.7184, 排名第4)
- 节点: 金(92.3%) 绝对主导; 论文: 金→23.3%, 水→40.0%, 火→16.7%
- **解读**: 知识树以"安全形式化"为核心，但论文已扩展到**LLM安全评估(水)、红队测试(火)**等更实证的方向

### 3.5 大语言模型 (漂移 0.6517, 排名第5)
- 节点: 金(35.7%)+水(57.1%); 论文: 土→43.3%, 木→20.0%, 金→0%
- **解读**: 从推理/形式化(金)转向**架构优化与训练系统(土)**和**生成式方法(木)**，RLVR、MoE、蒸馏等成为核心

### 3.6 AI 系统与硬件 (漂移 0.0471, 排名第13)
- 节点: 土(100%); 论文: 土(80.0%)
- **解读**: 唯一结构-活跃度高度吻合的领域，系统/硬件研究始终围绕基础设施优化

## 五、主要结论

1. **全领域平均漂移 0.5063 > 0.3 阈值** — AI知识体系的静态结构（知识树节点）与动态前沿（6月论文）整体存在显著结构性偏移，知识树需要系统性更新

2. **火行(+8.8%)是最大跨领域热点** — 智能体、评估、人机交互、工具使用等方向在全领域论文中全面活跃

3. **三大"结构性张力"领域**: 计算机视觉(生成式取代识别)、智能体(协作取代单体)、交叉领域(方法化取代应用化)

4. **AI 系统与硬件**是唯一结构-活跃度高度吻合的领域，说明该领域知识树与前沿研究同步良好

5. **计算机视觉 θ_critical=1.20** 触发失衡预警，建议优先更新该领域知识树节点

## 九、数据采集经验总结

### 9.1 数据源特征
- **科研月报系统**从2026年5月开始运营，无4月及更早数据
- 5月报通过 `reports_detail` API 采集，每个领域返回30篇代表论文
- 6月报通过 `reports_list` + `reports_detail` API 采集，13领域共387篇

### 9.2 关键教训
1. **软件工程与编程5月数据陷阱**: 该领域5月报的"代表论文"区块存储的是中文摘要而非英文论文标题，导致初始分析中五行分类完全错误，月际漂移虚高至1.1042。通过 `reports_detail` API 的 `ordered_list` 嵌套结构重新提取后修正
2. **五行分类器对中文文本无效**: 当前关键词分类器基于英文论文标题关键词匹配，中文摘要无法被正确分类
3. **数据验证是必须的**: 时间序列对比前务必检查每个领域的数据格式和质量
