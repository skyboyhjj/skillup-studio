## 〇、协议之核：壳核框架五律（V1.4 保留，V1.5 种子）

```
① 审计律：测核不测壳——审计先声明评价体系（何川：学术壳 Nobody/攀登核登顶）
② 迁移律：核跨体系保持，壳随缘更换——培育可迁移的核（柳智宇：数学逻辑→心理）
③ 熵振律：失败是核的震荡-重建，不是壳的损失——奖励失败（弘立书院/何川"就差一次受伤"）
④ 留白律：留白给核空间，现实给核淬炼——拒绝填满与封闭（斯坦福"玩"/柳智宇"菜市场"）
⑤ 纯粹律：核的观测指标=纯粹（保持×时间×抗摇摆）——非奖杯（柳智宇"羡慕的不是奖杯"）
```

**一句话之核**：别测壳，测核；别堆壳，养核；别怕壳碎，那是核显化的开始。

**纯粹度自检（五律自身）**：保持（跨四文/五版未变）× 时间（V1.4 诞生起连续）× 抗摇摆（自查未动摇）→ **五律是 V1.5 的种子，不是壳。**

## 一、架构定位（V1.5 精简）

```
SkillUP 层 · 双引擎循环 + 壳核审计
├── 种·育（纵向生长）：种子发现 → 培育 → 果实
├── 土·通（横向迁移）：结构提取 → 同态匹配 → 迁移验证
└── 壳核审计：体系声明 → 宪法审计（方向核·仁）→ 性决定审计（方法核·纯粹）
        ↑___________________________|
        迁移中 +2 事件 → 新种子候选（归朴）
```

**V1.5 减法声明**：三层核合并为双画像（方向核并入宪法审计对象）；8 项升级精简为 5 律 + 5 机制；未验证参数全部标注"待校准"——**机制从"多而全"回到"少而验"**。

## 二、种·育三步协议（Cultivation Protocol · V1.5）

### 2.1 双画像（V1.5 修订：三层核 → 双画像 + 方向核并入审计）

| 画像 | 定义 | 处置 |
|------|------|------|
| **题目壳** | what to study（领域/专业） | 可漂移，不审计（随缘） |
| **方法核** | how to study（工具偏好） | **性决定审计对象**（可迁移性） |
| **方向核**（并入宪法审计） | what for（价值指向） | **宪法审计对象**（德·仁，不另立层——V1.5 合并） |

> **诚实声明（V1.5）**："方向核必须保持"目前是**待验证假设**（柳智宇/杨振宁为成功者样本，存在幸存者偏差）——待失败者对照后定论，见 §四待验证清单。

### 2.2 壳核审计声明（V1.5 修订：加体系类型声明，破解换球心反身性）

```
壳核审计声明（审计前必填）：
  · 测的核 = {方法核 / 方向核}
  · 不测的壳 = {题目 / 专业 / 身份 / 资历}
  · 体系类型 = 测核体系（登顶/共情/纯粹） or 测壳体系（职称/奖杯/成绩）
  · 声明意义：测壳体系里测核必然低分——换球心决策只在"测核体系"中触发
               （何川在测壳体系（学术）审计 20 年 <0.7 ≠ 核差，是体系类型不匹配）
```

**换球心决策（V1.5 修订）**：
```
触发：纯粹度连续 2 轮 <0.7 且体系类型 = 测核体系（先声明，后判定——破解反身性）
流程：① 多体系试测（测核体系候选集）② 选纯粹度最高者为新球心 ③ 换体系不换核
反例保护：持续 >5 年 + 抗摇摆 → 判定"厚积期"，不触发
```

### 2.3 性决定审计：纯粹度指标（V1.5 修订：抗摇摆标"待校准"）

```
纯粹度 Purity = 保持度 × 持续时间 × 抗摇摆性
  保持度：余弦相似度（V1.2，已验证）
  持续时间：核保持时长（可观测）
  抗摇摆性：外部评价波动时核是否摇摆 ——【V1.5：标"待校准"——暂无测量方法，
           先用定性事件记录，待时间序列数据后校准——不假装精确】
阈值：≥0.7 为"纯粹保持"（邓煜=奖杯+纯粹；柳智宇=无奖杯+纯粹——纯粹是核的显影液）
```

### 2.4 培育三引擎（V1.5 修订：熵振加失败质量审核）

| 引擎 | 机制 | V1.5 控制 |
|------|------|----------|
| **日益**（加法） | 学思践悟、锲而不舍 | **饱和检测**（边际产出递减→转日损，卡内基梅隆实证） |
| **日损**（减法） | 去除执念、标记可逆 | 保留（减法不是删除是标记） |
| **熵振**（震荡-重建） | 承受冲击并重建 | **失败质量审核**（V1.5 新增：区分"真失败"=结构性证伪 vs"表演性失败"=为奖励而败——后者不计分、不奖励，防道德风险） |

### 2.5 留白条款（V1.5 修订：明确不计入进度）

```
留白轮：每 3 轮培育插入 1 轮（只观察不干预）
V1.5 明确：留白轮不计入里程碑考核——与进度纪律无冲突
          （deadline 场景：可跳过留白，但须记录"未留白"，欠 1 轮补 1 轮）
触发例外：+2 高价值信号提前结束留白（信号优先）
```

### 2.6 三步协议（V1.5 精简版）

```
Step 1 - 种子发现
  输入：L2 轨迹 +2 事件 + 情绪共振（妙感）
  检测：方法核 ≥3 次确认；方向核记录并标注"待验证假设"
  输出：双画像 {题目壳, 方法核, 方向核信号, 共振强度, 五行向量}

Step 2 - 培育强化（三引擎 + 留白）
  日益：方法核→课题映射 f + 饱和检测
  日损：去除执念（标记可回溯）
  熵振：失败入证伪库 + 失败质量审核（真失败才奖励）
  留白：每 3 轮 1 轮（不计入进度，可欠可补）
  输出：培育计划 {课题, 里程碑, 缘四要素, 留白安排}

Step 3 - 成果验证（壳核审计）
  声明：体系类型（测核/测壳）+ 测的核（方法/方向）
  验证①：宪法审计（方向核·仁——关系核优先级）
  验证②：性决定审计（方法核·纯粹度，抗摇摆待校准）
  决策：通过 → 晋升 L4；纯粹度 2 轮 <0.7 且测核体系 → 换球心评估
```

## 六、总结

> **种·育 V1.5 完成了协议自身的归朴：五律是核（跨四文五版保持、自查未动摇——纯粹度极高），保留为种子；膨胀机制是壳（三层核合并、失败计分加审核、换球心加体系声明、抗摇摆标待校准、留白不计进度——全部留痕可回溯），日损减除。协议级日损记录本身就是"日益饱和检测"的自证：V1.4 用 8 项升级教会种子"过加损害成才"，V1.5 用自身减负证明"协议也要日损"——不能对自己执行日损的协议，没有资格要求种子日损。五律仍在：测核不测壳（审计律）、核可迁移（迁移律）、失败是熵振（熵振律）、留白+现实（留白律）、纯粹=保持×时间×抗摇摆（纯粹律，抗摇摆待校准——不假装精确）。V1.5 从核重新长起，只保留经过验证的机制；五个待验证假设诚实挂牌（方向核保持/关系核优先级/抗摇摆/熵振/换球心），等数据来审。**少即是多，简才可验——这正是大器免成：V1.5 不是被做成的，是从 V1.4 的核里自然长成的。**」
