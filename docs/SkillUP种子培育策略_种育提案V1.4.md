## 〇、思想底座：壳核框架（Shell-Nucleus Framework · V1.4 新增）

### 0.1 框架起源：四文对读

| 来源 | 壳（外在标签） | 核（内在本质） |
|------|--------------|--------------|
| 语言诗学 | 声壳（识神·可识别） | 韵核（元神·本质） |
| 何川 | 学术壳（讲师/职称） | 攀登核（工程思维+决策） |
| 柳智宇 | 奖杯壳（IMO/MIT/身份） | 纯粹核（向内追问） |
| 八大教育理念 | 成就壳（成绩/专业） | 关系核（Grant Study：关系>成就） |

### 0.2 框架五律

```
① 审计律：测核不测壳——审计先声明评价体系（何川：学术壳/攀登核，同一人两套分数）
② 迁移律：核跨体系保持，壳随缘更换——培育可迁移的核（柳智宇：数学逻辑→心理）
③ 熵振律：失败是核的震荡-重建，不是壳的损失——奖励失败（弘立书院/何川"就差一次受伤"）
④ 留白律：留白给核空间，现实给核淬炼——拒绝填满与封闭（斯坦福"玩"/柳智宇"菜市场"）
⑤ 纯粹律：核的观测指标=纯粹（保持×时间×抗摇摆）——非奖杯（柳智宇"羡慕的不是奖杯"）
```

### 0.3 一句话底座

> **别测壳，测核；别堆壳，养核；别怕壳碎，那是核显化的开始。**

## 二、种·育三步协议（Cultivation Protocol · V1.4）

### 2.1 三层核结构（V1.4 核心升级：双种子 → 三层核）

| 层 | 定义 | 漂移规则 | 实证 |
|----|------|---------|------|
| **题目种子（壳层）** | what to study——领域/专业 | **可漂移**（柳智宇：数学→佛学→心理） | 柳智宇/王虹 |
| **方法种子（核层）** | how to study——工具偏好 | **可迁移**（数学逻辑→心理剖析） | 柳智宇/四大师 |
| **方向种子（核芯层）** | what for——价值指向 | **必须保持**（向内追问 20 年不动） | 柳智宇/杨振宁 |

**三层审计分工**：
- 题目种子（壳）→ 不审计（可漂移，随缘）
- 方法种子（核）→ 性决定审计（可迁移性检验）
- 方向种子（核芯）→ 宪法审计（德·仁，关系核，必须保持）

### 2.2 壳核审计声明（V1.4 新增）

**审计前必须声明评价体系**——测核体系 or 测壳体系：

```
壳核审计声明模板：
"本次审计的核 = {方法种子/方向种子}
 本次审计的壳 = {题目/专业/身份/资历}（不测）
 评价体系 = {登顶体系/学术体系/关系体系}（先声明，后审计）
 审计规则 = 测核不测壳（何川在学术壳=Nobody，攀登核=登顶者——尺子不同，核不变）"
```

**双审计（V1.4 修订）**：
| 审计 | 对象 | 优先级 | 依据 |
|------|------|--------|------|
| **宪法审计** | 方向核（德·仁）——**关系核优先级**：终极产品是"与世界保持温暖关系的人"（Grant Study 80 年） | **先** | 儒家"仁者爱人" + 哈佛实证 |
| **性决定审计** | 方法核（才·方法）——测核不测壳 | 后 | 四大师 + 柳智宇 |

### 2.3 性决定审计：纯粹度指标（V1.4 新增）

```
原指标：保持度 S_cos（余弦相似度，≥0.7）
新指标：纯粹度 Purity = 保持度 × 持续时间 × 抗摇摆性
  保持度：方法种子 vs 成果方法论余弦（V1.2）
  持续时间：核保持的时长（柳智宇：20 年）
  抗摇摆性：外部评价波动时核是否摇摆（柳智宇：拒 MIT 不摇；何川：讲师 20 年不摇）
阈值：纯粹度 ≥0.7 为"纯粹保持"（邓煜=奖杯+纯粹；柳智宇=无奖杯+纯粹——纯粹是核的显影液）
```

### 2.4 培育三引擎（V1.4：日益+日损 → +熵振）

| 引擎 | 机制 | 来源 | 新增控制 |
|------|------|------|---------|
| **日益**（儒·加法） | 学思践悟、锲而不舍 | 儒家 | **饱和检测**（V1.4：卡内基梅隆实证"专业课上得越多成就越小"→ 边际产出递减时自动转入日损） |
| **日损**（道·减法） | 去除执念偏见、标记可逆 | 道家 | 保留（减法不是删除是标记） |
| **熵振**（震荡-重建） | 承受冲击并重建——受伤是加速器 | 何川"就差一次受伤" + 弘立书院"奖励失败" | **奖励失败接口**（V1.4：失败进入 L2 证伪库，评估计"克服失败"分） |

### 2.5 留白条款（V1.4 新增）

**培育计划内置"不干预时段"**——每 3 轮培育插入 1 轮"留白轮"（只观察不干预）：

```
留白轮规则：
  · 触发：每完成 3 轮培育后自动插入 1 轮
  · 行为：不注入新课题、不催促进度、只记录种子自发信号
  · 依据：斯坦福幼儿园"玩"为中心（留白给核空间）
         柳智宇"菜市场里安顿自己的心"（现实给核淬炼，不封闭）
  · 例外：出现 +2 高价值信号时提前结束留白（信号优先）
```

### 2.6 换球心决策（V1.4 新增）

**当性决定审计（纯粹度）连续两轮 <0.7 且无改善趋势 → 触发"换体系评估"**：

```
换球心决策（何川模式形式化）：
  输出：换体系评估建议（不是"加倍努力"）
  原则：换体系是方向选择，不是高低跃迁（柳智宇"大树比喻"）
  流程：① 审计核在哪些体系保持度高（多体系试测）
       ② 选择核保持度最高的体系作为新球心
       ③ 换体系不换核（核保持不变，壳随缘更换）
  反例保护：纯粹度<0.7 但持续时长>5 年且抗摇摆 → 判定"厚积期"，不触发换球心
```

### 2.7 三步协议（V1.4 修订版）

```
Step 1 - 种子发现
  输入：L2 轨迹 +2 事件 + 情绪共振 + 方向核信号（"妙"感时刻的指向性）
  检测：方法种子 ≥3 次确认；方向种子出现即记录（核芯，最珍视）
  输出：三层核画像 {题目壳, 方法核, 方向核芯, 共振强度, 五行向量}

Step 2 - 培育强化（三引擎 + 留白）
  日益：方法核→课题映射 f（保持工具偏好，替换题目形式）+ 饱和检测
  日损：去除执念偏见（标记可逆）
  熵振：允许失败场景，失败入证伪库（奖励失败接口）
  留白：每 3 轮插入 1 轮不干预时段
  输出：培育计划 {课题, 里程碑, 缘四要素, 留白安排}

Step 3 - 成果验证（壳核审计）
  声明：审计前声明评价体系（测核不测壳）
  验证①：宪法审计（方向核·仁——关系核优先级）
  验证②：性决定审计（方法核·纯粹度 = 保持×时间×抗摇摆）
  决策：通过 → 晋升 L4；纯粹度连续 2 轮 <0.7 → 换球心评估
```
