## 交付物一：跨域诊断咨询技能 SOP v1.0（种子A）

### 1. 定位与适用范围

| 项 | 内容 |
|----|------|
| 技能ID | SKL-A-20260808-001 |
| 方法种子 | 同态映射三步协议（结构提取→同态匹配→迁移验证） |
| 服务定位 | 帮助客户把 A 领域已验证的方法论/能力迁移到 B 领域 |
| 适用边界 | 源域 ≥5 节点且有明确运算关系；源域 <3 节点不适用（双射退化） |
| 时间尺度 | 技能尺度（单次咨询 1-4 周 / 完整项目 1-6 月） |

### 2. 宪法审计条款（德·先于才）

| 条款 | 内容 | 判定 |
|------|------|------|
| **不宰** | 咨询只提供迁移地图与选项，不强制客户采纳（长而不宰） | 交付物含"可选方案"而非"唯一指令" |
| **溯源** | 每条关系标注来源与信度（善行无辙迹 → 如实标注） | 关系图每边带 source 字段 |
| **不假装精确** | 低信度映射标注"待验证"，不硬给结论（信度出口） | 保持度 <0.4 输出"暂未发现同态" |
| **无弃人** | 客户领域结构不佳 ≠ 客户无价值；标注"换缘/换方向"建议 | 建议文本含"待观察，非废材" |

### 3. 三步流程（v1.0 细化）

```
Step 1 结构提取（访谈+文档分析）—— W1
  · 提取客户源领域（A）的"概念-关系图"
  · 关系类型标注：生克 / 因果 / 层级 / 类比
  · 每条关系附信度：≥0.7 高信度 / 0.4~0.7 中 / <0.4 低（宽区间）
  · 输出：源域结构图 + 信度标注表

Step 2 同态匹配（映射设计）—— W1-2
  · 在目标领域（B）寻找与 A 结构匹配的候选映射 f
  · 关系保持度评分（0~1）：
      ≥0.7 → 进入验证
      0.4~0.7 → 标注"低信度候选"，验证场景 3→5 个
      <0.4 → 不强配（信度出口）
  · 输出：候选映射表 + 保持度评分 + 逐边检验记录

Step 3 迁移验证（试点检验）—— W2-4
  · ≥3 个场景检验 f 是否保持 A 的运算关系
    例：A 域"甲生乙"，检验 B 域 f(甲) 是否"生" f(乙)
  · 通过 → 固化迁移路径；失败 → 修正适用边界（记录证伪案例）
  · 输出：迁移路径图 + 验证记录 + 证伪边界标注
```

### 4. 案例模板（咨询案例记录格式）

```
案例编号：CASE-A-{日期}-{序号}
├── 基本信息：日期 / 源域A→目标域B / 客户类型
├── Step 1 记录：源域结构图（节点数/边数）+ 信度标注表
├── Step 2 记录：候选映射 f + 关系保持度评分（逐边）
├── Step 3 记录：≥3 场景验证结果 + 证伪边界
├── 宪法审计记录：4 条款通过情况（不宰/溯源/不假装精确/无弃人）
├── 减法记录（为道日损）：本次咨询删除了哪些"多余动作"
└── 交付物清单：迁移路径图 + 保持度报告 + 验证记录
```

### 5. 减法记录机制（为道日损）

| 减法事件类型 | 触发 | 处置 |
|------------|------|------|
| 去除过度流程 | 案例执行证明某步骤无信息增量 | 标记"已减除"，L0 留痕可回溯 |
| 去除模板冗余 | 模板字段 >10 且 >30% 为空 | 合并/删除字段，版本号 +0.1 |
| 去除咨询执念 | 顾问对低信度映射仍强行输出 | 触发宪法审计 REJECT，记录案例 |

**原则**：减法不是删除，是标记（L0 可回溯，可逆）。

## 交付物二：五行七维分析模板 v1.0（种子B）

### 1. 定位与适用范围

| 项 | 内容 |
|----|------|
| 技能ID | SKL-B-20260808-001 |
| 方法种子 | 五行诊断七维指标体系（频次/矩阵/路径/熵/重心/画像/判语） |
| 服务定位 | 对任意领域的"概念集合"输出五行诊断画像（跨学科通用） |
| 适用边界 | 节点 ≥5 且带层级关系；节点 <5 打宽信度区间 |
| 已验场景 | 道德经六章 / MIT文章 / 智源Agent / BAAI知识树 / 语言谱系树 |

### 2. 宪法审计条款（德·先于才）

| 条款 | 内容 | 判定 |
|------|------|------|
| **溯源** | 每个节点五行标注标注来源与依据 | 节点 JSON 含 wuxing_source 字段 |
| **不曲解** | 数据不支持的观点不写进判语 | 判语引用数据行号，可回溯 |
| **不假装精确** | 小样本打宽区间，不硬下结论 | 节点<10 领域：信度区间宽度 >0.3 时判语加"低信度"前缀 |
| **无弃人** | 低信度领域 ≠ 无价值领域 | 报告含"待观察领域"清单（非废材） |

### 3. 七维计算模板（v1.0 通用化）

```
输入：标准化节点-关系图 JSON {nodes, edges, layers}

维度1 五行频次：各五行节点数/总数 → 占比 + wilson 信度区间
  · 输出：{木:x%, 火:x%, 土:x%, 金:x%, 水:x%} + ci_low/ci_high

维度2 层×五行矩阵：种子/现行/超越 × 五行 → 分布矩阵
  · 输出：3×5 矩阵（识别"层间分布不均"）

维度3 重心偏移路径：层间五行重心的迁移轨迹
  · 输出：种子层重心 → 现行层重心 → 超越层重心（向量序列）

维度4 五行熵 H：H = -Σpᵢ·log₂(pᵢ)（归一化）
  · 判定：H 高 → 多元均衡；H 低 → 单极主导

维度5 重心向量：五行占比合成向量（主导五行判定）
  · 输出：主导五行 + 次主导 + 三元组合

维度6 特质画像：矩阵+熵+路径的组合解读（库扩展）
  · 输出：画像库匹配（当前 7+ 画像，V1.3 目标 12+）

维度7 一句话判语：阶段判定（通/变/化/克/生）+ 信度标注
  · S_p 广义平均（p=0.5 恕度）→ 阶段 + effective_n 报告

输出：五行画像报告（含全部信度区间，不假装精确）
```

### 4. 信度标注规范（v1.0）

| 场景 | 信度处理 |
|------|---------|
| 节点 ≥50 | 窄区间（wilson，confidence_level=高） |
| 10 ≤ 节点 <50 | 中区间（confidence_level=中） |
| 节点 <10 | 宽区间 + 判语"低信度"前缀（不假装精确） |
| effective_n <3 | S_p 输出区间值（上界/下界），不输出单点 |

### 5. 案例模板（分析案例记录格式）

```
案例编号：CASE-B-{日期}-{序号}
├── 基本信息：分析对象 / 节点数 / 层结构
├── 数据采集：JSON 快照（含 wuxing_source 溯源字段）
├── 七维计算：7 个维度输出（含信度区间）
├── 宪法审计记录：4 条款通过情况（溯源/不曲解/不假装精确/无弃人）
├── 减法记录：本次分析删除了哪些"多余维度/冗余字段"
└── 交付物：画像报告 + 信度区间 + 判语 + 数据快照
```

### 6. 减法记录机制（为道日损）

| 减法事件类型 | 触发 | 处置 |
|------------|------|------|
| 去除冗余维度 | 某维度在 ≥3 案例中零信息增量 | 标记"已减除"，可回溯 |
| 去除模板冗余字段 | 字段 >12 且 >30% 为空 | 合并/删除，版本 +0.1 |
| 去除分析执念 | 对低信度数据仍写强判语 | 宪法审计 REJECT，记录案例 |
