## 2. 图谱模型

### 2.1 双视图设计

```
视图1 · 五行生态环（总览）
  木(11) → 火(6) → 土(34) → 金(6) → 水(24) → 木   （相生环，实线）
  木克土  土克水  水克火  火克金  金克木             （相克，虚线）
  节点大小 ∝ 章数（土 r=73 最大，火/金 r=39 最小）

视图2 · 章节生克四邻（点击展开）
  任一章 → 母(生我) / 子(我生) / 所不胜(克我) / 所胜(我克)
  如第10章（土）：母=火6章 · 子=金6章 · 克我=木11章 · 我克=水24章
```

### 2.2 生克规则（生克化通变话语体系）

| 关系 | 定义 | 示例 |
|------|------|------|
| 生 | 木→火→土→金→水→木（相生环） | 土章生金章 |
| 克 | 木克土 土克水 水克火 火克金 金克木（隔位） | 土章克水章 |
| 同气 | dominant 相同 | 34 土章两两同气 |
