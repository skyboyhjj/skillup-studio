## 二、词典级校验：同名概念必须同五行（规则定案）

**用户强调的校验规则**（迁移到 75 章时强制）：

| # | 规则 | 说明 |
|---|------|------|
| R1 **继承优先** | 75 章标注时，概念已在词典 → **必须用词典五行**（禁止重新标注） | 种子权威 |
| R2 **冲突仲裁** | 新章标注与词典冲突 → **以词典为准** + 记录差异（待人工复核） | 词典不可被新标注覆盖 |
| R3 **新概念入典** | 词典没有的概念 → 提示词标注 → **入典**（词典版本化 v1.0→v1.1） | 词典生长 |
| R4 **强制校验** | S2 输出后跑"词典一致性检查"——**跨章同名概念五行 diff = 0** | 与标注治理"四同步"同构 |

**校验时机**：
```
S2 批量标注 75 章 → 词典一致性检查（R4）→ diff>0 则仲裁（R2）→ 入典（R3）→ 版本化
```

**与既有体系的呼应**：这本质是标注治理"canonical 四同步"在经典层的复现——**概念五行词典 = 经典层的 canonical**。
