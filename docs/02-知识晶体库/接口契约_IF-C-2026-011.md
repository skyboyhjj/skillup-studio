**数据接口（现有）**：
- 前端读 `../data/dashboard_data.json`（schema v1.1，多路径 fallback）
- 后端桥接 `verified_server.py`：`GET /api/verified`、`POST /api/verify`、`POST /api/unverify`（localStorage 离线 + 后端 JSON 持久化，以后端为可信源）

### 1.2 缺口

tracker 目前只**展示诊断数据**，无用户互动入口。SOP Step 1-7 的完整镜鉴闭环（事件→反馈→践行→体证→回流）未接入。本地已就绪的脚本（S3 生成器 / B-1 填证 / B-2 入池 / S4 检索）无前端通道。

### 1.3 目标

在 tracker.html 新增**镜鉴入口区（zone9）**，实现：

```
用户输入事件 + 四维评分
  → [MIRROR:EVENT] 匹配镜鉴反馈（第X章·维度·级别 + 洞察/功课/反思）
  → TizhengCard 生成（draft）
  → 用户践行后填"证"三问（draft→completed）
  → 可选匿名化入池（completed→published，三道护栏）
  → S4 检索回显（智慧条目 + 样本量/匿名级别）
```

**原则**：前端只做 UI 编排，逻辑全部走本地 Python 脚本（与 verified_server.py 桥接模式一致）；**隐私默认本地**——事件文本不出机器，仅入池时走匿名化。

## 三、后端 API 契约（verified_server.py 扩展）

### 3.1 新增端点总览

| 端点 | 方法 | 功能 | 对应脚本 |
|------|------|------|----------|
| `/api/mirror/event` | POST | 事件+评分 → 镜鉴反馈（含五行补益） | build_tizheng_card 逻辑（预览，不落盘） |
| `/api/mirror/card` | POST | 生成 TizhengCard（draft，落盘） | build_tizheng_card.py |
| `/api/mirror/complete` | POST | 填"证"三问 → completed | complete_tizheng.py |
| `/api/mirror/pool` | POST | 三道护栏 → 匿名入池 | pool_tizheng.py |
| `/api/mirror/retrieve` | GET | S4 检索（五行/关键词/类型） | retrieve_crystals.py |
| `/api/mirror/cards` | GET | 列出个人卡片（draft/completed） | 扫描 tizheng/ |

### 3.2 请求/响应规格

**POST /api/mirror/event**（预览镜鉴反馈，不落盘）
```json
// 请求
{ "event": "刚才会议上，我对下属的提案很不耐烦",
  "scores": { "shi": 7, "yu": 6, "identify": 3, "yuan": 5 } }
// 响应 200
{ "ok": true,
  "mirror": { "chapter": 10, "dimension": "识位轴", "p_level": "低",
              "trigger_hit": ["不耐烦"], "classic": "载营魄抱一",
              "insight_desc": "镜鉴：您可能陷入了固定的思维框架。",
              "action_desc": "尝试放下一个执着的观点，只是观察而不评判",
              "reflection": "当您放下这个观点时，内心发生了什么变化？" },
  "wuxing": { "weak": "水", "lowest_dimension": "识位轴",
              "recommend": ["第1章 · 道可道", "第4章 · 道冲", "第6章 · 谷神不死", "第7章 · 天长地久", "第8章 · 上善若水"],
              "weak_chapter_count": 24 } }
```

**POST /api/mirror/card**（生成 draft 卡片，落盘 tizheng/）
```json
// 请求 = /api/mirror/event 请求 + { "user": "hjj" }
// 响应 200
{ "ok": true, "card": "tizheng/tizheng_hjj_20260812_160000.md",
  "status": "draft", "path": "output/crystals/tizheng/tizheng_hjj_....md" }
```

**POST /api/mirror/complete**
```json
// 请求
{ "card": "tizheng/tizheng_hjj_....md",
  "done": "今天会议上我忍住没打断下属，先听完完整提案",
  "experience": "发现耐心听完后，提案里有两个可行点是我急着反驳时看不到的",
  "cognition": "验证了'急躁遮蔽信息'——慢一步看全貌" }
// 响应 200（自检通过）
{ "ok": true, "status": "completed", "evidence": { "word_count": {...} } }
// 响应 422（自检拦截，不流转）
{ "ok": false, "error": "自检未通过", "problems": ["experience 缺少具体情境——请补充具体体验细节"] }
```

**POST /api/mirror/pool**（三道护栏）
```json
// 请求（首次：无 confirm → 返回预览 + 护栏结果）
{ "card": "tizheng/tizheng_hjj_....md" }
// 响应 200（护栏 1/2 通过，等待确认）
{ "ok": false, "stage": "await_confirm",
  "preview": { "title": "体证洞察：……", "summary": "……" },
  "scan_boundary": "匿名化：尽力而为（模式扫描）。已扫描：姓名/手机/邮箱/身份证/公司名/地点；未扫描：上下文推断性识别" }
// 响应 422（护栏拦截）
{ "ok": false, "error": "护栏1 · 匿名化核验未通过", "hits": ["[手机号] 命中: 13812345678"] }

// 请求（用户确认后）
{ "card": "tizheng/tizheng_hjj_....md", "confirm": true }
// 响应 200
{ "ok": true, "wisdom_id": "w-20260812-160000-a3f2b1",
  "verified": "human:anonymous", "sample_size": 1,
  "anonymization": "best-effort", "chapter": 10 }
```

**GET /api/mirror/retrieve**（S4 检索，透传）
```json
// 请求: /api/mirror/retrieve?bu=水 | wuxing=木&kw=无为&status=draft&type=WisdomInsight
// 响应: retrieve_crystals.py --json 输出（直接透传）
```

**GET /api/mirror/cards**
```json
// 响应 200
{ "ok": true, "cards": [
  { "file": "tizheng/tizheng_hjj_....md", "status": "draft", "title": "体证：……（识位·低）", "created": "2026-08-12T16:00:00Z" },
  { "file": "tizheng/tizheng_hjj_....md", "status": "completed", "title": "体证：……（识位·低）", "completed_at": "..." } ] }
```

### 3.3 错误码约定

| 状态码 | 场景 |
|--------|------|
| 200 | 成功（含护栏 awaiting confirm 的 ok:false 预览） |
| 400 | 参数缺失/非法（scores 非 1-10、event 为空） |
| 404 | 卡片文件不存在 |
| 422 | 业务校验失败（自检/护栏拦截——带 problems/hits 明细） |
| 500 | 脚本执行异常（错误堆栈写入服务端日志） |

```html
<section class="bg-card rounded-xl border border-border p-4 sm:p-6" id="zone9">
```

### 4.2 交互规格

| 交互 | 规格 |
|------|------|
| 评分默认 | 5 分（中性）；最低分维度高亮为"核心关注" |
| 获取反馈 | POST /api/mirror/event → 渲染镜鉴卡片（📖 章节 + 洞察/功课/反思 + 五行补益） |
| 生成卡片 | 反馈确认后 POST /api/mirror/card → 提示"已生成 draft 卡片" |
| 填证提交 | POST /api/mirror/complete → 422 时逐条红字显示 problems（含"请补充具体情境"指引） |
| 匿名上传 | POST /api/mirror/pool → 首次展示预览 + 扫描边界说明（confirm 按钮确认）→ 成功显示 wisdom_id |
| 检索 | GET /api/mirror/retrieve → 结果列表（WisdomInsight 带"体证 N 人 · 匿名化：best-effort"徽标） |
| 离线模式 | 后端不可达时隐藏 zone9（与现有 fetch 多路径 fallback 一致） |
