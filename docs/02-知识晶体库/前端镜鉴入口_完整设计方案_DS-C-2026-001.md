### 2.3 build_mirror_data.py 规格

- 输入：`wuxing_flowengine/data/daojing_database_v2.json`
- 输出：`hui-skill-product-matrix/data/mirror_data.json`
- 逻辑：
  1. 遍历 81 章，提取 `chapter_title`、`dominant`、`dist`
  2. 遍历每章的 `dimensions.*.*.triggers/insight_desc/action_desc/reflection`
  3. 按 `dominant` 分组生成 `wuxing_chapters` 索引
  4. 注入 `dimension_wuxing`、`dimension_keys`、`dimension_cn` 常量
- 行数：~30 行
- 触发时机：`daojing_database_v2.json` 更新后手动运行

## 三、在线模式：mirror_server.py

### 3.1 架构（复用 verified_server_参考.py 模板）

```
mirror_server.py
├── ThreadingHTTPServer（端口 8080，可配置）
├── MirrorHandler(SimpleHTTPRequestHandler)
│   ├── 静态文件服务（hui-skill-product-matrix/）
│   ├── do_OPTIONS（CORS 预检）
│   ├── do_GET
│   │   ├── /api/mirror/health       → 心跳检测
│   │   ├── /api/mirror/retrieve     → S4 检索
│   │   └── /api/mirror/cards        → 卡片列表
│   └── do_POST
│       ├── /api/mirror/event        → 事件→镜鉴反馈
│       ├── /api/mirror/card         → 生成体证卡片
│       ├── /api/mirror/complete     → 填证自检
│       └── /api/mirror/pool         → 三道护栏入池
```

### 3.2 端点详细规格

#### `GET /api/mirror/health`
- 响应：`{ "ok": true, "mode": "mirror", "version": "1.0" }`
- 用途：前端模式检测（2 秒超时 → 离线降级）
- 行数：~5 行

#### `POST /api/mirror/event`
- 请求体：
  ```json
  {
    "event": "会议上对下属提案感到不耐烦",
    "scores": { "shi": 7, "yu": 6, "identify": 3, "yuan": 5 }
  }
  ```
- 响应：
  ```json
  {
    "lowest_dimension": "识位轴",
    "weak_wuxing": "水",
    "p_level": "低",
    "mirror": {
      "chapter": 10,
      "title": "载营魄抱一",
      "dimension": "识位轴",
      "triggers": ["困惑", "固执", "纠结"],
      "insight_desc": "...",
      "action_desc": "...",
      "reflection": "..."
    },
    "recommendations": ["第1章 · 道可道", "第4章 · 道冲", ...],
    "weak_chapter_count": 24
  }
  ```
- 实现：调用 `build_tizheng_card.py` 的匹配逻辑（抽取为函数），不生成文件
- 行数：~40 行

#### `POST /api/mirror/card`
- 请求体：同 `/api/mirror/event`
- 响应：
  ```json
  {
    "ok": true,
    "card_path": "output/crystals/tizheng/tizheng_hjj_20260812_200000.md",
    "card": {
      "frontmatter": { ... },
      "body": "..."
    }
  }
  ```
- 实现：调用 `build_tizheng_card.py`，生成 draft 卡片文件
- 行数：~50 行

#### `POST /api/mirror/complete`
- 请求体：
  ```json
  {
    "card_path": "output/crystals/tizheng/tizheng_hjj_20260812_200000.md",
    "evidence": {
      "practice": "我在下次会议中先深呼吸，听完再回应",
      "experience": "发现耐心倾听后，对方的方案其实有可取之处",
      "reflection": "验证了'执一不失'——放下评判才能真正看见"
    }
  }
  ```
- 响应：
  ```json
  {
    "ok": true,
    "card_path": "...",
    "status": "completed",
    "x_evidence": {
      "word_count": 120,
      "has_situation": true,
      "depth": "deep"
    }
  }
  ```
- 实现：调用 `complete_tizheng.py`，draft→completed
- 行数：~45 行

#### `POST /api/mirror/pool`
- 请求体：
  ```json
  {
    "card_path": "output/crystals/tizheng/tizheng_hjj_20260812_200000.md",
    "confirm": true
  }
  ```
- 响应（首次无 confirm）：
  ```json
  {
    "ok": false,
    "stage": "preview",
    "guard_1": { "pass": true, "scanned": "姓名/手机/邮箱", "unscanned": "上下文推断" },
    "guard_2": { "pass": true, "depth": "deep", "guidance": null },
    "preview": { "wisdom_path": "output/crystals/wisdom/w-20260812-200000-abc123.md", "sample_size": 1, "anonymization": "best-effort" },
    "action": "请确认后发送 confirm:true"
  }
  ```
- 响应（confirm: true）：
  ```json
  {
    "ok": true,
    "wisdom_path": "...",
    "db_updated": { "chapter": 10, "tizheng_count": 2 }
  }
  ```
- 实现：调用 `pool_tizheng.py`，三道护栏 → 入池
- 行数：~55 行

#### `GET /api/mirror/retrieve`
- 查询参数：`?type=WisdomInsight` 或 `?bu=水` 或 `?kw=无为`
- 响应：同 `retrieve_crystals.py` 输出
- 行数：~35 行

#### `GET /api/mirror/cards`
- 查询参数：`?status=draft` 或 `?status=completed`
- 响应：`{ "cards": [{ "path": "...", "title": "...", "status": "...", "generated": "..." }] }`
- 行数：~20 行

## 四、离线模式：客户端引擎

### 4.1 核心算法（JavaScript，与 Python 等价）

```javascript
// 伪代码——实际实现见 tracker.html zone9 脚本
const MIRROR = {

  // 加载 mirror_data.json
  async load() { ... },

  // 步骤 1：最低维度 → 五行
  analyze(scores) {
    const dims = ["时位轴", "宇位轴", "识位轴", "缘位轴"];
    const lowest = dims.reduce((a, b) => scores[a] < scores[b] ? a : b);
    return {
      lowest_dimension: lowest,
      weak_wuxing: DATA.dimension_wuxing[lowest],
      p_level: scores[lowest] < 5 ? "低" : "高"
    };
  },

  // 步骤 2：触发匹配（遍历 chapters，命中 triggers）
  match(event, lowestDim, pLevel) {
    for (const [num, chapter] of Object.entries(DATA.chapters)) {
      const dim = chapter.dimensions?.[lowestDim]?.[pLevel];
      if (!dim) continue;
      const hit = dim.triggers.filter(t => event.includes(t));
      if (hit.length > 0) {
        return { chapter: parseInt(num), title: chapter.title, dimension: lowestDim,
                 p_level: pLevel, triggers: hit, insight_desc: dim.insight_desc,
                 action_desc: dim.action_desc, reflection: dim.reflection };
      }
    }
    // fallback：第1章 识位轴·低
    return this.fallback(lowestDim, pLevel);
  },

  // 步骤 3：推荐经典
  recommend(weakWx) {
    const chapters = DATA.wuxing_chapters[weakWx] || [];
    return chapters.map(n => {
      const ch = DATA.chapters[n];
      return `第${n}章 · ${ch.title}`;
    });
  }
};
```

## 六、在线模式：填证 + 入池交互流

### 6.1 完整流程

```
[生成卡片] → [内联展示]
                │
                ├─ [下载 .md]
                │
                ├─ [填证 ✍]（仅在线）
                │    │
                │    ├─ 弹出填证面板（实操/体验/反思三个 textarea）
                │    ├─ 提交 → POST /api/mirror/complete
                │    ├─ 返回 422 → 展示建设性指引
                │    │   "请补充具体情境（时间/地点/人物/行为）"
                │    └─ 返回 200 → 卡片状态更新为 completed
                │
                └─ [入池 ✦]（仅在线，需 completed）
                     │
                     ├─ 首次点击（无 confirm）
                     │   POST /api/mirror/pool
                     │   → 返回护栏预览
                     │   → 展示：
                     │     ┌── 入池预览 ──────────────┐
                     │     │ 护栏1 · 匿名化：已扫描    │
                     │     │ 护栏2 · 完整度：深度体证  │
                     │     │ 护栏3 · 确认入池？        │
                     │     │                            │
                     │     │ 池条目：w-20260812-*.md    │
                     │     │ 信任标记：体证1人·匿名化   │
                     │     │                            │
                     │     │ [确认入池]  [取消]         │
```

## 九、边界与约束

### 9.1 数据一致性

- JS 匹配算法与 Python 匹配算法输出必须一致
- 验收方法：同一组输入（event + scores），离线卡片与在线卡片内容逐字段比对
- `mirror_data.json` 生成脚本确保数据源唯一

### 9.2 安全性

- 离线模式：事件文本不离开浏览器
- 在线模式：事件文本仅发送到本地 `mirror_server.py`（127.0.0.1），不出机器
- 池条目匿名化：护栏 1 扫描姓名/手机/邮箱，标注"best-effort"

### 9.3 兼容性

- 不修改现有 zone 1-8 HTML 结构和数据逻辑
- 不修改 `dashboard_data.json` 和现有 JS 数据加载流程
- 仅新增 zone 9 和 nav 按钮，现有功能零影响

### 9.4 部署

- 离线模式：`tracker.html` + `mirror_data.json` 部署到 Cloudflare Pages，无需服务器
- 在线模式：`python mirror_server.py` 本地运行，访问 `http://localhost:8080/pages/tracker.html`

### 9.5 已知限制

- 离线模式无法使用填证/入池/检索（需 Python 环境）
- `mirror_data.json` 需随 `daojing_database_v2.json` 更新后手动重新生成
- 在线模式的 `mirror_server.py` 使用 subprocess 调用 Python 脚本，首次启动可能有冷启动延迟（~1-2s）
