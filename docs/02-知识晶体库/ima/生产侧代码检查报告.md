## 二、确认 Bug：quality_gate.py 运行即崩（ImportError）

### 症状

```python
# quality_gate.py 第 22 行
from data_validator import validate_tree_file, VALID_WUXING
```

**实测**：
```
❌ ImportError: cannot import name 'validate_tree_file' from 'data_validator'
```

### 根因（接口双重错位）

| 项 | quality_gate 期望 | data_validator 实际 | 错位 |
|----|------------------|--------------------|------|
| 函数名 | `validate_tree_file(tree, source, m, hist)` | `validate_tree(tree, filepath, history, excludes)` | ❌ 名字+参数签名都不匹配 |
| 常量 | `VALID_WUXING` | 无（只有 WUXING_ORDER） | ❌ 缺失 |
| 返回格式 | `result[checkpoint]` 为字符串（`r.startswith("FAIL")`） | `result[checkpoint]` 为 dict（`{"status","message"}`） | ❌ 即使函数名修好，格式也不匹配 |

**结论**：quality_gate.py 与 data_validator.py 是分别更新的，**未联调**——quality_gate 一运行即 ImportError，且按当前接口即使修复导入也无法正确解析检查结果。

### 修复建议

```python
# quality_gate.py 修改（对齐 data_validator 实际接口）
from data_validator import validate_tree, WUXING_ORDER as VALID_WUXING
# ...
result = validate_tree(tree, str(f), history_dict, excludes)
# 检查结果解析（dict 格式）
for ck, r in result["checks"].items():
    if r["status"] == "fail": all_failures.append(...)
    elif r["status"] == "warn": all_warnings.append(...)
```
