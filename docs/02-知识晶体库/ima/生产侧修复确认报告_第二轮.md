## 二、新发现：量级检查静默失效（🔴 需再修）

### 症状

quality_gate 的 `run_quality_gate()` 中：

```python
# quality_gate.py（错误）
history[source][m] = len(...nodes)          # ① 存的是 n_nodes（节点数）
hist = {k: v for k, v in history.get(source, {}).items() if k < m}   # ② {month: n_nodes}
result = validate_tree(tree, filepath, hist, excludes)                # ③ 传 {month: n_nodes}
```

data_validator 的 `check_volume()` 期望：

```python
# data_validator.py（契约）
src_history = history.get(src, [])     # 期望 {source: [weight 列表]}
if not src_history or len(src_history) < 2:
    return "pass", "无历史可比（total=...），记录基线"   # ← 永远走到这里
```

### 错位机制

| | quality_gate 提供 | data_validator 期望 |
|---|---|---|
| 键 | 月份（`"2026-06"`） | source（`"arxiv"`） |
| 值 | n_nodes（节点数） | total_weight（权重总量） |
| 结构 | `{month: n_nodes}` | `{source: [weights]}` |

`history.get(src, [])` → 键不匹配 → **None** → falsy → 返回 pass"记录基线"——**量级检查（检查点 4）永不真正执行，静默失效**（不崩溃、不告警，只是永远通过）。

### 影响

- 量级异常（月中样本 2,519 vs 均值 12,000+、HF 截断、GitHub rate limit 缺失）**不会被 quality_gate 检测到**
- 与 data_validator 单跑（--dir 直接跑）行为不一致——**同数据、两个入口、两种结果**

### 修复建议（quality_gate.py 两处）

```python
# ① history 存 total_weight（对齐契约语义）
history[source][m] = sum(n.get("weight", 0) for n in info["tree"].get("nodes", []))

# ② 构造 {source: [weights]} 传给 validate_tree
tree_month = tree.get("month", "")
hist_weights = {s: [history[s][mm] for mm in sorted(history[s]) if mm < tree_month]
                for s in history}
result = validate_tree(tree, filepath, hist_weights, excludes)
```
