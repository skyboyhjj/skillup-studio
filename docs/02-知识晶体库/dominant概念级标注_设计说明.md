## 一、为什么 dominant 需要"概念级标注"？

### 问题：维度映射推不出每章 dominant

```
dimension_map = {识位→水, 缘位→木, 宇位→土, 时位→火}（全局定案）
→ 每章四维等权 → 五行分布恒为 {木:25%, 火:25%, 土:25%, 水:25%}
→ dominant 恒平局，无区分度
```

维度映射是**全局结构**（每章都有四维），而 dominant 需要**每章内容差异**——差异来自章的具体概念/义理，必须"概念级"标注。

### 本质

> dominant = 每章**内容**的五行画像（这章主要讲什么行），不是**结构**的五行映射（四维归五行）。前者要读章，后者是定案。

---

## 二、概念级标注是什么

给每章的**核心概念与 SPO 主语/宾语**打五行标签，统计分布得 dominant：

```
第1章 核心概念: 道、无、有、玄、妙
  ├─ 道 → 水（道体如流水/渊深）？
  ├─ 无 → 水？金？（无名天地之始——虚极→水？）
  ├─ 有 → 木？（万物之母→生发）？
  ├─ 玄 → 水（玄深如渊）？
  └─ 妙 → ？
统计: 水 3 / 木 1 / … → dominant = 水
```

## 三、数据源与标注方法（三选，组合使用）

### 方法 A：复用既有标注（零成本起步）

**关键发现**：本地《道德经_第X章.json》（莫比乌斯环数据）的 concepts **已带 wuxing 字段**！

```json
{"label": "道可道非常道", "desc": "可言说的道不是恒常之道…", "wuxing": "水", "bagua": "☵坎"}
```

- 覆盖：6 章（01/02/03/79/80/81）——**可立即算出这 6 章的 dominant**（v0.1 已演示）
- 扩展：把这 6 章的概念→五行作为**种子词典**，迁移到其余 75 章（同名概念继承）

### 方法 B：概念五行标注提示词（批量）

仿照 SPO 提示词，写"概念五行标注提示词"：

```
【角色】烧火童子 × 五行学专家
【任务】为《道德经》核心概念标注五行（木火土金水）
【规则】
  1. 依概念语义定行（生长→木、明断→火、承载→土、肃敛→金、润下/智→水）
  2. 一概念一行（歧义时选最显著语义，标注备选）
  3. 输出 JSON: {"concept": "道", "wuxing": "水", "alt": ["金"], "basis": "道体渊深，润下不争"}
【批次】81 章 core_concepts（每章 3-8 个概念，共 ~400 个）→ 分批标注
```

- 初标后**人类导师抽检仲裁**（每批 10 章抽 2-3 章）——与"AI 初审 + 导师修订"模式一致
- 产出：**概念五行词典**（概念→五行，可复用/版本化）——这是重要资产！

### 方法 C：SPO 语义辅助

597 条 SPO 的 subject/object 可辅助校验（如"道生之"→ 道与生发的关系）——但 SPO 是关系不是实体，仅作交叉验证，不作主源。

## 四、dominant 计算与校验

### 计算

```
每章: concepts_wuxing = [概念1→水, 概念2→水, 概念3→木, …]
dominant = 频率最高行（平局时按 WUXING_ORDER 序取，标注 tie）
分布 = {行: 占比}
```

### 校验（KSMG G5 精神）

| 检查 | 方法 |
|------|------|
| 合理性 | dominant 与五步读解"核心智慧晶体"（每章结论）人工抽检对照——如第 1 章结论"道不可言说"→ 水（虚静）应吻合 |
| 一致性 | 种子词典迁移的概念，两章同概念必须同五行（词典级校验） |
| 覆盖 | 81 章全有 dominant + 分布（无 None） |
