## 3. 设计要点

| 设计 | 说明 |
|------|------|
| **引用不复制** | 运行时扫描 frontmatter 构建索引，不内嵌正文大数据（契约 §2.4） |
| **五行统一匹配** | 经典/诊断按 `dominant`；体证按 `weak`（缺失行）——三类语义对齐 |
| **生克上下文** | 补益输出含母/子/所不胜/所胜——"生克化通变"话语体系落地 |
| **双输出** | Markdown（人读）默认 / JSON（机器读 `--json`）——View 层前端可直接消费 |
| **组合过滤** | `--type` + `--wuxing` + `--status` AND 语义可叠加 |
