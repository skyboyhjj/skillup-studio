## 二、S3 体证卡片 Schema 升级（基于反馈库）

### 2.1 TizhengCard v0.2（对齐反馈库模型）

```yaml
---
type: TizhengCard
title: 我在会议中觉察到"不耐烦"（识位·低）
status: draft                       # 待填写/已完成/需修订（反馈库 Status 对齐）
generated: { by: user:<id>@镜鉴, at: 2026-08-11T10:00:00Z }
verified: { by: user:<id>, at: 2026-08-11T10:00:00Z }    # 用户亲证
x-mirror:                           # 关联镜鉴条目（升级：不再是三字段，而是条目引用）
  id: ch10-识位-低
  chapter: 10
  dimension: 识位轴
  p_level: 低
  trigger: 不耐烦
  classic: 涤除玄鉴，能无疵乎？
x-scores:                           # 四维自评（反馈库 Step 4）
  shi: 7
  yu: 6
  shi_identify: 3                  # 最低维度 = 核心关注维度
  yuan: 5
x-wuxing:
  dominant: 水                       # 可选项：维度 → 五行映射（识位→水？需定映射）
x-relation:
  validates: [ref: classical-10]     # 验证了哪个 ClassicalInsight 晶体
  challenges: [ref: classical-03]
sources:
  - id: mirror-ch10-识位-低
    resource: 镜鉴反馈库20251224.xlsx#ch10-识位-低
---
# 体证正文
## 事件
刚才会议上，我对下属的提案感到很不耐烦…
## 镜鉴反馈（关联条目生成）
📖 老子在第10章说：涤除玄鉴，能无疵乎？
**今日功课**：下次有说话冲动时，先停三秒…
🤔 那个"不耐烦"的背后，是什么在推动你？
## 体证记录（践行后）
我试了三次停三秒，发现…（用户填写）
```

### 2.2 数据流（对齐反馈库触发流程 7 步）

```
事件描述 → 关键词提取 → 匹配反馈库条目 → 四维自评
→ 最低维度 → 关联镜鉴条目（chapter×dim×level）→ 生成反馈
→ 用户践行 → 体证记录 → 封装 TizhengCard → 回流公共智慧池
```

### 2.3 与反馈库 SOP 的字段映射

| 反馈库字段（xlsx） | TizhengCard 位置 | 说明 |
|---------------------|------------------|------|
| Trigger Keywords | x-mirror.trigger | 匹配用户事件 |
| Insight Description | 正文·镜鉴反馈 | 状态洞察（"镜鉴："开头） |
| Core Principle | x-mirror.classic | 经文依据 |
| Action Description | 正文·今日功课 | 行动建议（微修行） |
| Reflection Prompt | 正文·反思引导 | 引导体证记录 |
| Status | 晶体 status | 待填写/已完成/需修订 |

## 三、S2 的连带收益

反馈库的 **Core Principle**（经文+白话解释）与 **Action Category**（观照/静默/布施/关系/简化/觉察/感恩）可回注 ClassicalInsight 晶体：

```yaml
# ClassicalInsight v0.2 新增
x-application:
  action_categories: [觉察练习, 静默练习]
  mirror_dimensions: [识位轴, 时位轴]    # 该章覆盖的镜鉴维度
```

**收益**：View 层检索可"按行动类别"查经典（如"我今天需要静默练习 → 找相关章"）——**经典与践行的双向检索**。
