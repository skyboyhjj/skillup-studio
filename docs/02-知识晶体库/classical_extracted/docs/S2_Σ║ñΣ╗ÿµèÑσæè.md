## 2. 设计要点

### 2.1 晶体格式（契约 IF-2026-006 对齐）

```yaml
---
type: ClassicalInsight          # 契约合法类型
title: 第1章 · 道可道，非常道
description: 道德经第1章概念解读（可言说的道不是恒常之道…）
status: draft                   # AI 初审；导师确认 → current
generated: { by: build_classical_crystals/0.1, at: ... }
sources:
  - id: 道德经_第01章
    resource: 道德经_第01章.json
x-wuxing:
  dominant: 水                  # 由 concepts 五行统计
  wuxing_dist: {水: 4, 金: 1, 木: 1}
  bagua: ☰乾, ☳震, ☵坎
---
正文：核心概念（label+五行+八卦+desc）+ 五行分布 + Base 铁律说明
```

### 2.2 关键设计决策

| 决策 | 理由 |
|------|------|
| **draft 无 verified** | 契约语义：未验证 = 无 verified 字段（避免 `draft:ai-initial` 非法格式） |
| **导师确认 = --verified-by** | status 自动 current + verified: human:<id>——Base 铁律（AI 初审 + 人类导师深度修订）工程化 |
| **每章一个晶体** | 概念在正文列出，不细到每概念（奥卡姆：避免 81 章 × 每章多概念 = 数百晶体） |
| **x-wuxing 由概念统计** | 章节主导行可参与五行诊断（Base 层 → 诊断层打通） |

### 3.2 契约校验（G6 精神自检）

- type ∈ VALID_TYPES ✅
- draft → 无 verified（合法）✅
- 确认模式 → verified: human:huihui-master + status=current ✅
- x-wuxing.dominant ∈ 五元素 ✅

### 3.3 插曲（契约校验抓设计错误）

首版 `verified: draft:ai-initial` 被 `VALID_VERIFIED` 正则拦截（`process:xxx|human:xxx`）——**这正是契约价值**：draft 状态不应有 verified（未验证语义），修正为 verified 置空。契约第一次在 Base 层发挥作用。
