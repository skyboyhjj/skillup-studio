# 《道德经》第68-70章 五步协同读解报告

## 第68章：不争之德 配天古极

### 一、文本细读

**原文**：善为士者不武，善战者不怒，善胜敌者不与，善用人者为之下。是谓不争之德，是谓用人之力，是谓配天古之极。

**版本校勘**：帛书甲本"为士"作"为士"，"不与"作"弗与"；帛书乙本略同；王弼本"配天古之极"——帛书甲本作"配天古之极"，乙本同。郭店楚简无此章。关键差异在"不与"之"与"：王弼注"与，争也"，河上公注"不与敌争"；帛书作"弗与"，语气更决绝。另一异文在"配天古之极"——有版本作"配天古之极"（无"古"字），然帛书甲乙均有"古"字，今从帛书。

**字词溯源**：(1) "士"——《说文》"士，事也"，本义为治事之官。此处"善为士者"指善于担任将帅者，非泛称士人。王弼注"士，卒之帅也"，点明其军事指挥身份。(2) "与"——王弼训为"争也"，《说文》"与，党与也"，引申为结党对抗、正面交锋。"不与"即不正面冲突对抗，避开锋芒。(3) "配"——《说文》"配，酒色也"，本义为调和酒味，引申为匹配、契合。"配天古之极"意为与天道之最高准则相契合。

**句读辨析**："是谓配天古之极"——传统句读作"配天，古之极"。另一种读法连读为"配天古之极"（天古连文，指"自古以来的天道"）。从帛书"天古"连言之状考之，连读更合古貌。"古之极"即自古以来的最高准则，全句意为"这就是契合自古以来天道的最高准则"。

### 二、语境建构

**历史语境**：本章承第67章"我有三宝"之后，将"慈""俭""不敢为天下先"的哲学原则具体化于军事指挥领域。春秋末期，兵学勃兴，《孙子兵法》已传世，"不战而屈人之兵"与老子"善胜敌者不与"形成思想共振。同时，吴越争霸、晋楚争雄之际，"怒而兴师""愠而致战"的教训屡见不鲜——老子以"不怒""不与"为善战之要，具有明确的现实批判指向。

**文本内证**：(1) 第31章"兵者不祥之器……不得已而用之，恬淡为上"——本章"善为士者不武"即"恬淡为上"在将领修养上的落实。(2) 第66章"江海所以能为百谷王者，以其善下之"——"善用人者为之下"是"善下"原则在领导力中的直接应用。(3) 第73章"勇于敢则杀，勇于不敢则活"——"善战者不怒"正是"勇于不敢"的军事智慧。

**思想脉络**：本章构建了老子的"不争军事学"——不武（不恃勇力）、不怒（不因情绪）、不与（不正面交锋）、为之下（谦下待人），最终归结为"不争之德"。这一逻辑链将第67章"不敢为天下先"的伦理原则发展为可操作的军事领导方法论，是老子"以柔克刚"思想在兵学领域的完整呈现。

### 三、争议辨析

**争议一："不与"的确切含义**。王弼注"不与，不争也"，以"与"为争夺、对抗。河上公注"不与敌争，而敌自服也"，亦以不争为解。宋代吕惠卿解"不与"为"不与敌遇"（不与之正面遭遇），后世多从。**最优解判定**：从"不武""不怒""不与""为之下"四者之递进关系看，"不与"居第三位，介于"不怒"（情绪控制）与"为之下"（态度谦下）之间，应当是指战术层面的"不与之正面交锋"。三家之解实相通——不正面冲突即是不争之一种，此解最合军事语境。

**争议二："配天古之极"中"古"的去留**。有学者认为"古"为衍文，原文当作"配天之极"。然帛书甲乙本均存"古"字，出土简帛证明"古"当有之。**最优解判定**：从帛书保留"古"字来看，"配天古之极"是原貌，"天古"连言指天道之恒久性——"自古以来的天道极致"，既强调道的超时间性，又赋予"不争之德"以神圣根源，故应保留"古"字。

### 四、逻辑与体系验证

**逻辑链**：善为将者不恃武力 → 善于作战者不因怒而动 → 善于取胜者不正面冲突 → 善于用人者谦下待人 → 此为不争之德 → 此为善用人力之道 → 此为天道极致。由具体行为准则递进至抽象道德原则，再上升到天道本体，形成完整的哲学论证。

### 五、意义转化

**古今贯通**：本章为当代"领导力"理论提供了东方思想资源。"不武"即不以权势压人，"不怒"即情绪管理能力，"不与"即不陷入无谓的零和博弈，"为之下"即服务型领导（Servant Leadership）。现代管理学所谓"第五级领导"——谦逊而坚韧，与此高度暗合。

**三条实践路径**：(1) **领导力修炼**：在冲突管理中实践"不怒"——遇事先冷静24小时再做决策。(2) **团队建设**：以"为之下"服务团队成员，定期询问"我能为你做什么"而非"你为我做了什么"。(3) **竞争策略**：在商业竞争中践行"不与"——避开红海正面厮杀，寻找差异化蓝海空间。

### 赋能方案

**每日镜鉴**：遇到人际冲突时，在心中默念"不武→不怒→不与→为之下"四步法，逐次检查自己的状态，至少完成前两步再回应。

**互动哲学概念卡片**：「不争之德」概念卡——正面："善为士者不武，善战者不怒，善胜敌者不与，善用人者为之下"，背面思维实验：(1) 假设你是团队负责人，遇到一个公开挑战你权威的下属，你会如何体现"不武"与"为之下"？(2) 回顾最近一次你因情绪冲动而后悔的决策，如果当时做到了"不怒"，结果会如何？(3) 设计一个"不争竞争"的商业方案——找到你能以合作替代对抗的市场机会。

**用户画像道商维度**：核心维度为"不争领导力"——评估个体在权力运用中保持谦逊与克制的程度。子指标包括：情绪控制力、冲突转化力、谦下容众力和无为成就力。成长建议：每月阅读一本非权力型领导的传记，在团队中尝试一次"隐身领导"——支持他人成功但不居功。

## 第69章：哀兵必胜 轻敌丧宝

### 一、文本细读

**原文**：用兵有言：吾不敢为主而为客，不敢进寸而退尺。是谓行无行，攘无臂，执无兵，扔无敌。祸莫大于轻敌，轻敌几丧吾宝。故抗兵相若，哀者胜矣。

**版本校勘**：帛书甲本"执无兵"作"执无兵"，"扔无敌"作"乃无敌"；帛书乙本"扔无敌"作"乃无敌矣"；王弼本"执无兵扔无敌"连读。郭店楚简无此章。关键差异在"扔"字：帛书作"乃"（于是，而），王弼本作"扔"（牵引、对抗）。现代学者高明从帛书，读为"执无兵，乃无敌"——"乃至无敌"之意，句式更通畅。

**字词溯源**：(1) "主/客"——《说文》"主，灯中火主也"，引申为主位、主动；"客，寄也"，引申为客位、被动。老子以"不敢为主而为客"倡导守势，与《孙子兵法》"先为不可胜"的战略思想相通。(2) "攘"——《说文》"攘，推也"，即推让、排斥。"攘无臂"意为挥动却无臂可挥——在"无"的境界中行动。(3) "宝"——指第67章"我有三宝"之慈、俭、不敢为天下先。"轻敌几丧吾宝"意为轻敌几近丧失我之三宝（尤其是"慈"）。

**句读辨析**："行无行攘无臂执无兵扔无敌"——传统读作四句排比："行无行，攘无臂，执无兵，扔无敌"（行军无阵可列，奋臂无臂可伸，执兵无兵可握，对敌无敌可抗）。帛书"执无兵乃无敌"则读作二句"执无兵，乃无敌"——"不执兵器，于是无敌"。两种读法哲学意涵不同：前者强调"无"的否定性存在，后者强调因果逻辑。从全章反轻敌、尚慈哀的主旨看，排比读法更合老子"无"之哲学气质。

### 二、语境建构

**历史语境**：本章是老子全书中最集中的军事哲学论述之一，直接引用古兵家之言（"用兵有言"），表明老子吸收了春秋兵学的既有思想资源。"不敢为主而为客，不敢进寸而退尺"反映了一种以守为攻、以退为进的战略哲学，与当时诸侯争战中普遍存在的"先发制人"思维形成鲜明对照。战国后期，秦赵长平之战中赵括轻敌冒进致四十万众被坑杀，恰是"祸莫大于轻敌"的血证。

**文本内证**：(1) 第67章"我有三宝……一曰慈，二曰俭，三曰不敢为天下先"——本章"轻敌几丧吾宝"直接回扣"三宝"，慈为三宝之首，"哀者"即怀慈者。(2) 第31章"兵者不祥之器……杀人之众，以悲哀泣之"——"哀者胜"即"以悲哀泣之"者在战场上的胜利，哀非软弱，而是对生命的深切慈悲。(3) 第36章"将欲歙之，必固张之"——"不敢为主而为客"是"将欲取之，必固与之"的军事哲学表达，均属以退为进、以柔克刚的辩证策略。

**思想脉络**：本章将第67章"三宝"的抽象伦理落实到具体军事情境中。"不敢为主而为客"对应"不敢为天下先"，"不敢进寸而退尺"对应"俭"（节制），"哀者胜"对应"慈"（悲悯）。由此，老子的三宝哲学完成了从形而上学到战争伦理的完整贯通。

### 三、争议辨析

**争议一："哀者胜"的确切含义**。王弼注："哀者必相惜而不趋利避害，故必胜"，以"哀"为悲哀、哀悯，引申为同仇敌忾。河上公注："哀者慈仁，士卒不远死"，亦以慈解哀。历代注家多将"哀"与"慈"贯通——哀兵即怀慈之兵。然而现代学者刘笑敢指出"哀"亦有"哀矜"（怜悯）与"哀痛"（悲愤）双重意涵——被侵略一方因哀痛而士气高昂。**最优解判定**：二义兼容。"哀"内蕴"慈"（悲悯生命）与"愤"（哀兵必胜）的双重力量——怀悯者不忍轻启战端，故不轻敌；被侵略者的哀痛凝聚为强大的战斗意志，故能胜。此解最合"慈故能勇"（第67章）的内在逻辑。

**争议二："行无行攘无臂"是否玄虚不可解**。有学者认为此四句过于玄虚，纯属修辞铺排。王弼注："行无行，言无迹也；攘无臂，言不怒也；执无兵，言不伤也；扔无敌，言不争也"，以道德训诫解之。河上公注："行无行，不妄动；攘无臂，不妄怒"——亦将玄虚句还原为实践准则。**最优解判定**：王弼、河上公的"道德化解法"最具解释力——此四句不是玄虚的诡辞，而是对"无为"在军事中的具体化描述：行军而不露行迹，奋臂而不露臂形，执兵而不见兵器，对敌而无可对之敌——皆是无为而无不为的境界刻画。

### 四、逻辑与体系验证

**逻辑链**：兵法古训：不敢主动进攻宁取守势 → 不敢前进一寸宁退一尺 → 如此则：行军无可列之阵，奋臂无可伸之臂，执兵无可执之兵，对敌无可抗之敌（进入"无"的境界） → 反训：最大的祸患是轻敌 → 轻敌几近丧失我之三宝 → 故势均力敌时，哀悯者胜。

### 五、意义转化

**古今贯通**："不敢为主而为客"为当代国际关系中的"防御性现实主义"提供了哲学依据——一个国家不以先发制人为战略，不追求霸权扩张，而以自身安全为边界。"哀者胜"则揭示了一种深刻的社会规律：弱势者的悲悯与愤怒转化为社会变革的动力，远胜强者的傲慢与轻敌。

**三条实践路径**：(1) **谈判策略**：在商业谈判中践行"不敢为主而为客"——先倾听、先理解，后回应；先让步（退尺）以建立信任，再争取核心利益。(2) **社会行动**：理解"哀者胜"——社会弱势群体的"哀"（对不公的清醒认知与悲悯）是最强大的动员力量。(3) **自我竞争**：在个人成长中警惕"轻敌"——对任何挑战保持敬畏，以"哀者"的谨慎心态面对困难。

### 赋能方案

**互动哲学概念卡片**：「哀者胜」概念卡——正面："祸莫大于轻敌，轻敌几丧吾宝。故抗兵相若，哀者胜矣"，背面思维实验：(1) 设想你即将参加一场竞争激烈的面试，如何以"哀者"（谨慎敬畏、不轻敌）而非"骄者"心态准备？(2) 在社交媒体上，你是更常扮演咄咄逼人的"主方"还是理性回应的"客方"？试做一周"客方实验"。(3) 历史上有哪些"哀者胜"的案例（弱势方以悲悯与谨慎战胜强势方）？分析其关键因素。

**用户画像道商维度**：核心维度为"哀德指数"——评估个体对他人处境的共情力与对挑战的敬畏心。包含"慈之深度"（悲悯他人）、"敬之广度"（敬畏事物）和"慎之强度"（谨慎行事）三个子指标。成长建议：每月深入访谈一位生活境遇迥异于己的人，记录其故事并反思，以此训练"哀"的能力——既保持悲悯，又从中获得前行的力量。

## 第70章：被褐怀玉 知希则贵

### 一、文本细读

**原文**：吾言甚易知，甚易行。天下莫能知，莫能行。言有宗，事有君。夫唯无知，是以不我知。知我者希，则我者贵。是以圣人被褐而怀玉。

**版本校勘**：帛书甲本"被褐"作"被褐"，"怀玉"作"怀玉"；帛书乙本同；王弼本文字与帛书一致。郭店楚简无此章。此章版本异文极少，历代传本高度统一，表明文本在流传中保持稳定。关键校勘点仅"则我者贵"——有本作"则我贵"，少"者"字，然帛书与王弼本均有"者"字。

**字词溯源**：(1) "宗"——《说文》"宗，尊祖庙也"，本义为宗庙，引申为根本、宗旨。"言有宗"即言语有宗旨、有根本依据，非空洞漫说。(2) "君"——《说文》"君，尊也"，本义为君主，引申为主宰、纲要。"事有君"即行事有主宰、有纲领，非任意妄为。(3) "褐"——《说文》"褐，粗衣也"，以粗毛或麻编织的贫贱者之衣。"被"通"披"，被褐即身披粗布短衣，喻外表的朴素无华。

**句读辨析**："夫唯无知是以不我知"——传统读为因果复句："正因（世人）无知，所以不了解我"。此为最自然的读法。"知我者希则我者贵"——"希"通"稀"（稀少），"则"可训为"效法"（《说文》"则，等画物也"，引申为法则、效法）或"那么"（连词）。河上公注"则，法也"——"知我者愈少，则效法我者愈尊贵"；王弼注"唯深故知之者希也，知我益希，我亦无匹"——"知我者稀，故我显得尊贵"。两解义理相通。

### 二、语境建构

**历史语境**：本章可能作于老子思想遭遇冷落的特定时期。春秋末至战国初，诸侯竞相延揽法家、兵家、纵横家之士，老子的"无为""不争"学说因"不切于实用"而受冷遇。"吾言甚易知甚易行，天下莫能知莫能行"透露出一种智者的孤独——其学说平易近人却无人践行，此一感慨成为千载哲人的共同心曲。孔子亦有"莫我知也夫"之叹（《论语·宪问》），可见圣贤孤独是轴心时代的思想家共同经验。

**文本内证**：(1) 第41章"上士闻道，勤而行之；中士闻道，若存若亡；下士闻道，大笑之"——本章"天下莫能知莫能行"是对第41章"下士闻道大笑之"的概括性重述，均表达道之不行于世的无奈。(2) 第43章"不言之教，无为之益，天下希及之"——与本章"知我者希"相呼应，"希及""希知"皆言道之难遇难行。(3) 第78章"天下莫不知，莫能行"——与本章"甚易知莫能行"几乎同句，属老子反复强调的核心困境命题。

**思想脉络**：本章是全书的自我反思性章节——老子从"论道"转向"论道之遭遇"，以"被褐怀玉"的自画像作结。这一自况揭示了老子思想的核心悖论：道至简至易，却因世人之"无知"（非知识匮乏，而是对道的无明）而难以知、难以行。第70章与第1章"道可道非常道"形成首尾呼应——道本不可言说，既已言说却无人懂得，哲人的命运便是"被褐怀玉"。

### 三、争议辨析

**争议一："则我者贵"中"则"的诠释**。王弼注"知我益希，我亦无匹"——以"则"为语辞，不特训。河上公注"则，法也。知我者少，法则我者贵"，明确释"则"为"效法"。现代学者陈鼓应取河上公说，译为"取法我的人就难得"。**最优解判定**：河上公以"则"为"效法"最合先秦语用——上句"言有宗，事有君"设定言行皆有准则，下句"知我者希，则我者贵"——"则"与"宗""君"对文，均含"准则、根本"之义。故当以河上公为正——"了解我的人稀少，但效法我的人将获得真正的尊贵"。

**争议二："被褐怀玉"是自况还是普遍命题**。有学者认为"圣人被褐而怀玉"仅是老子的自画像。另一派认为这是普遍命题——所有体道者都以朴素外在包裹内在珍宝。**最优解判定**：两种理解不可偏废。从语境看，此句确有自况之意（回应"知我者希"），但从全书看，"被褐怀玉"与第45章"大巧若拙，大辩若讷"属同一范式——"外朴内珍"是道家理想人格的普遍特征。故当兼取二义：既是老子的自况，也是圣人形象的普遍概括。
