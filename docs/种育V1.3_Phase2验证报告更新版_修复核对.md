## 二、残留问题（3 处）

### 残留一（P0-1 引出的新矛盾）：阶段判定与修复后的 S_p 不匹配

```
B-1：S_p = 12.93 → 判语"火·化阶段"   ← 化阶段区间是 [35, 40)，12.93 不在其中！
B-2：S_p = 20.10 → 判语"木·生阶段"   ← 生阶段区间是 [25, 30)，20.10 不在其中！
```

**量纲修好了，但阶段判定没跟上**——12.93 与 20.10 都低于"生"的下限 25，严格说应判"未入阶段/萌芽前"，而不是"化"和"生"。要么阶段阈值在小样本模式下有另一套逻辑（需说明），要么判语是旧数据残留。**这是量纲修复后必须同步修复的连带问题。**

### 残留二（P1-1 遗留）：A-1 映射是"域内关系"而非"跨域映射"

```
A-1 声明：源域=语言谱系树 → 目标域=慧惠 Agent 体系
映射内容：m1 f(音韵对应→语系分化) / m2 f(词汇同源→语法演化) / m3 f(语义漂移→音韵对应)
```

**映射内容全部是"语言谱系内部的运算关系"**（音韵→分化、同源→演化、漂移→音韵）——它们是源域内部的关系，不是"语言→慧惠"的跨域映射。跨域映射应该是"语系→架构层、同源词→跨域候选、借词→增量审计"之类（目标域概念）。**需要澄清映射的方向性**：是"源域关系在目标域的对应物"（应出现目标域概念），还是源域内部关系描述（那 Step 2 就还没进入目标域）。

### 残留三（P1-2 原样）：并列主导规则仍未处理

B-1 火=土=水=33.3% 判"火"、B-2 五者=20% 判"木"——并列时取第一个的规则仍未说明。**建议**：并列时输出"并列主导清单"（如"火/土/水并列主导"），或明确优先级规则。
