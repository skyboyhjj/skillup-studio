## 三、新发现（4 处联动问题——V1.5 机制间的接口）

### 问题①：纯粹度初期必然 WARN——换球心反例保护尺度不匹配

```
§5.2：双种子 Purity = 0.500（保持度 1.0 × 时间 0.5 × 抗摇摆 1.0）→ WARN
§8.1：换球心触发 = 纯粹度连续 2 轮 <0.7；反例保护 = 持续 >5 年
```

**技能尺度培育第 3 周，时间项天然 0.5 以下 → 纯粹度必然 <0.7 → 必然 WARN。** 而反例保护"持续 >5 年"是人才尺度——技能尺度（6 个月）下保护失效，**WARN 会持续积累 → 误触发换球心**。需要：按时间尺度缩放反例保护（技能尺度：持续 >2 个月且抗摇摆 → 判定"积累期"不触发）。

### 问题②：饱和检测在留白轮误报

```
§8.2：当前第 3 轮 = 留白轮（只观察不干预）
§8.3：饱和检测 = 已饱和（边际产出 0.0200 < 0.1）→ 转日损
```

**留白轮不产出 → 边际产出天然为 0 → 判"已饱和"是留白的正常结果，不是日益饱和。** 饱和检测应**跳过留白轮**（留白轮的零产出不计入边际产出序列），否则"留白"与"饱和"同时亮灯，信号矛盾。

### 问题③：失败分类"可复现=False"判定为"表演性失败"——语义存疑

```
§6 失败质量审核：表演性失败（结构性证伪=False），依据"证伪条件=True，可复现=False，修正方向=True"
```

**"不可复现"≠"表演性"**：不可复现更接近"偶然失败"（运气/环境），表演性失败是"为奖励而故意制造"——两者动机完全不同。当前分类把"偶然失败"归入"表演性失败"（都不奖励），**语义混淆**。建议三分：真失败（结构性证伪，奖励）/ 偶然失败（不可复现，中性不奖惩）/ 表演性失败（故意为之，警告）。

### 问题④：统计口径变化未声明——"全程累计 13 条"→"18 条"

```
§3 末尾：M3 减法记录 6 条（Phase 2 全程累计: 18 条）——上一版是 13 条
§9.4：培育级 6 + 协议级 5 = 合计 11
```

**18 ≠ 11，13 → 18 的构成未说明**。推测：18 = 培育级全程累计 13 + 协议级 5——但报告未声明口径变化。建议：统一标注"全程累计 = 培育级 13 + 协议级 5 = 18"，避免歧义。

### 问题⑤：新旧审计口径并存——M3 并列清单 vs 纯粹度

§5.2 已启用纯粹度审计（0.500 WARN），但 M3 并列清单（§四）B 案例仍用旧口径"七维骨架完整≡通过"——**同一报告两套性决定审计口径并存**。建议：并列清单统一改用纯粹度结果（或注明"旧口径归档，新口径见 §5.2"）。
