## 三、核心方法详解

### 3.1 双审计：`_constitution_audit()` + `_nature_determination_audit()`

宪法审计（德·仁）优先于性决定审计（才·方法），在 `_harvest_fruit()` 中按序执行：

```
宪法审计 ──REJECT──→ 短路返回（不执行性决定审计）
    │
    PASS
    │
    ▼
性决定审计（余弦相似度）
```

**宪法审计检查项**：

| 检查项 | 判定逻辑 | 经典依据 |
|--------|----------|----------|
| 方向越界检查 | 方法种子五行与课题五行是否相克 | 骥不称其力，称其德也 |
| 性分自觉检查 | 验证通过率是否低于 30%（缘主导区） | 不强求保持正是知的开始 |
| 减法优先检查 | 培育迭代 > 5 轮且通过率 < 50% | 为道日损 |
| 善行无辙迹检查 | 压力测试场景是否强制通过 ≥ 2 个 | 大器免成 |

**短路机制**：任一检查 REJECT → 整体不通过 → 立即返回，性决定审计跳过。

### 3.2 减法引擎：`_nurture_subtraction()`

与加法引擎（为学日益）并行运行，在培育过程中去除积累的执念/偏见/多余。

**减法事件类型**：
- **去除过度积累**：培育迭代超出基准时触发
- **去除五行偏离**：缘四要素中 mentor/environment/topic 五行偏离方法种子时记录
- **去除执念**：缘主导区强行培育时触发

**设计原则**：减法操作全部留痕（L0 可回溯），可逆。减法不是删除，是标记。

### 3.3 孔子六阶段：`_get_confucius_stage()`

根据种子活力自动映射孔子六阶段：

| 种子活力 | 孔子阶段 | 五行对应 |
|----------|----------|----------|
| 休眠/萌发 | 十五志于学 | 木·生 |
| 生长 | 三十而立 | 火·化 |
| 开花 | 四十不惑 | 金·克 |
| 结果（seedney < 0.85） | 五十知天命 | 土·通 |
| 结果（0.85 ≤ seedney < 0.95） | 六十耳顺 | 水·变 |
| 结果（seedney ≥ 0.95） | 七十从心 | 道·合 |

### 3.4 导师差异化 + 环境分阶段：`_build_environmental_factors()`

**导师差异化**（因材施教）：
- 金性种子（子路式）→ 严厉收敛（克）
- 木性种子（冉有式）→ 温和鼓励（生）
- 不宰伦理：生而不有，为而不恃，长而不宰——导师是缘不是因

**环境分阶段**：
- 子夏保护期：修身初期，选择性保护
- 子张包容期：成熟后，广泛包容，允许跨域碰撞

### 3.5 归朴命名：`_detect_reverse_flow_seeds()`

"通中生种"字段重命名为"归朴"（`source: "归朴"`），经典引用更新为《道德经》第 28 章"复归于朴"。

### 3.6 无弃人底线：`_generate_advice()`

低信度种子（确认状态 = "待观察"）的建议中显式添加无弃人保证：
> 圣人常善救人，故无弃人。——此种子为'待观察'，非'废材'。建议换缘/换方向，不丢弃。
