# hui-skill.cn 架构设计文档

## 1. 项目概述

hui-skill.cn 是一个面向知识工作者的智能研究平台，以道境空间（中国哲学）为知识底色，以 AI 技术为处理引擎，提供知识图谱标注、概念地图可视化、知识树追踪、论文采集等核心能力。

### 1.1 设计理念

项目视觉与交互设计遵循三条核心原则：

- **东方美学 × 现代科技**：墨色为底、朱砂红为辅、宣纸白卡片承载内容，以留白与呼吸感替代传统 SaaS 密集信息布局
- **渐进式权限**：游客即可体验核心功能（浏览、预设生成），注册用户解锁完整工具链
- **零依赖构建**：纯静态 HTML + CDN 运行时，无需 Node.js 构建工具，直接部署至 Nginx

### 1.2 核心指标

| 维度 | 目标 |
|------|------|
| 首屏渲染 | 无构建工具延迟，CDN 加载 Tailwind + Lucide 后即可渲染 |
| 设计 Token 覆盖率 | 100%（所有颜色/圆角/间距通过 CSS 变量引用） |
| 页面数 | 2 个已上线（产品矩阵首页 + 标注平台），2 个规划中 |
| 权限层级 | 2 级（游客 / 注册用户） |
| 响应式 | 桌面端优先，标注平台支持移动端侧边栏折叠 |

## 3. Design Token 体系

### 3.1 架构概览

Token 体系采用三层级联结构：

```
CSS 自定义属性 (:root)          ← 品牌原始值
        │
        ▼
Tailwind @theme inline          ← 桥接至 Tailwind 类名
        │
        ▼
语义 Token 回退类               ← 兜底兼容（非 Tailwind 场景）
```

### 3.2 完整 Token 清单

#### 品牌主色

| Token | 值 | 用途 |
|-------|-----|------|
| `--brand-primary` | `#C94B3A` | 主按钮、链接、强调元素 |
| `--brand-primary-hover` | `#B33E2E` | 主按钮悬停态 |
| `--brand-primary-foreground` | `#FFFFFF` | 主色背景上的文字 |
| `--brand-primary-light` | `rgba(201,75,58,0.08)` | 主色淡底（选中态背景） |
| `--brand-primary-medium` | `rgba(201,75,58,0.15)` | 主色中底（hover 态背景） |

#### 中性色

| Token | 亮色 | 暗色 | 用途 |
|-------|------|------|------|
| `--brand-background` | `#FAF8F5` | `#141210` | 页面底色 |
| `--brand-foreground` | `#1A1715` | `#EDE8E3` | 文字主色 |
| `--brand-card` | `#FFFFFF` | `#1C1A17` | 卡片/面板底色 |
| `--brand-card-foreground` | `#1A1715` | `#EDE8E3` | 卡片内文字 |
| `--brand-muted` | `#F2EFEB` | `#252320` | 次要背景 |
| `--brand-muted-foreground` | `#6B6560` | `#9B948E` | 次要文字 |
| `--brand-border` | `#E5E0DA` | `#2E2B27` | 边框/分割线 |
| `--brand-input` | `#E5E0DA` | `#2E2B27` | 表单控件边框 |
| `--brand-ring` | `rgba(201,75,58,0.35)` | `rgba(201,75,58,0.45)` | 聚焦环 |

#### 形状系统

| Token | 值 | 用途 |
|-------|-----|------|
| `--brand-radius-sm` | `4px` | 小控件（输入框、徽章） |
| `--brand-radius-md` | `8px` | 表单控件、小卡片 |
| `--brand-radius-lg` | `12px` | 按钮、中等卡片 |
| `--brand-radius-xl` | `16px` | 大卡片、面板 |

#### 语义状态色

| Token | 值 | 用途 |
|-------|-----|------|
| `--state-success` | `#2D8C4E` | 成功/已完成 |
| `--state-warning` | `#C97A2A` | 警告/进行中 |
| `--state-error` | `#C94B3A` | 错误/失败 |
| `--state-info` | `#3A6BC9` | 信息/提示 |

### 3.3 Token 引用规范

所有页面内样式必须通过 CSS 变量引用 Token，禁止硬编码颜色值：

```css
/* 正确 */
.page-root { background-color: var(--brand-background); }

/* 错误 */
.page-root { background-color: #FAF8F5; }
```

## 4. 页面架构

### 4.1 页面公共基础设施

每个页面 `<head>` 包含以下标准块：

```
<head>
  ├── <style id="theme-vars">         ← 品牌 Token 内联定义
  ├── <script> Tailwind CDN           ← Tailwind CSS v4.3.1 浏览器运行时
  ├── <script> Lucide CDN             ← Lucide Icons v1.8.0
  ├── <style type="text/tailwindcss"> ← @theme inline 桥接
  └── <style id="semantic-token-fallback"> ← 语义 Token 回退类
```

### 4.2 产品矩阵首页（index.html）

**页面类型**：展示型（showcase）  
**视口模式**：文档滚动（document-scroll）  
**主题**：暗色模式（墨色底）  

**布局结构**：

```
┌──────────────────────────────────────────────┐
│  Hero 区域                                    │
│  ├── 品牌标题 "hui.skill"                     │
│  ├── 副标题 "道境空间 × AI 知识引擎"           │
│  ├── 产品描述文案                             │
│  └── 权限指示器（游客 / 注册用户）              │
├──────────────────────────────────────────────┤
│  产品卡片区域（非对称 12 列网格）               │
│  ├── 第一行 (7:5)                             │
│  │   ├── 知识图谱标注平台 [大卡片]              │
│  │   └── 莫比乌斯概念地图 [中卡片]              │
│  └── 第二行 (5:7)                             │
│      ├── 知识树追踪引擎 [中卡片 · 即将上线]     │
│      └── 论文采集器 [大卡片 · 即将上线]         │
├──────────────────────────────────────────────┤
│  Footer                                      │
│  ├── 版权信息                                 │
│  └── 导航链接（关于我们 / 联系方式 / 使用条款）  │
└──────────────────────────────────────────────┘
```

**关键设计决策**：避免 3 列均等 Feature Card 模板，采用非对称 7:5 / 5:7 交错布局，营造品牌叙事节奏感。

### 4.3 知识图谱标注平台（annotate.html）

**页面类型**：任务驱动型（task-driven）  
**视口模式**：文档滚动（document-scroll）  
**主题**：亮色模式（宣纸白底）  
**布局风险**：密集分栏面板 + 树深度滚动 + 多表单项  

**布局结构**：

```
┌──────────────────────────────────────────────────────────┐
│  顶部导航栏                                               │
│  ├── 品牌名 "hui · skill"                                │
│  ├── 面包屑 "标注平台"                                    │
│  ├── 权限切换按钮（游客 ↔ 注册用户）                        │
│  └── 返回矩阵链接                                         │
├──────────────────┬───────────────────────────────────────┤
│  左侧面板 (320px) │  右侧面板 (flex-1)                      │
│  ┌──────────────┐│  ┌───────────────────────────────────┐│
│  │ 搜索框        ││  │ 空状态提示                        ││
│  │ 展开/折叠全部  ││  │ 或                                ││
│  │              ││  │ 标注表单卡片网格 (2列)              ││
│  │ 概念层级树     ││  │ ├── 五行 (下拉)                   ││
│  │ ├── 根节点    ││  │ ├── 多层五行深度 L1-L4 (4个下拉)   ││
│  │ │  ├── 类A   ││  │ ├── 认知深度 (下拉)               ││
│  │ │  │  ├── 项1││  │ ├── 八卦 (下拉)                   ││
│  │ │  │  └── 项2││  │ ├── 概念描述 (textarea 全宽)       ││
│  │ │  └── 类B   ││  │ └── 来源出处 (input)              ││
│  │ └── ...      ││  │                                   ││
│  │              ││  │ 保存 / 重置 按钮                    ││
│  │              ││  │                                   ││
│  │              ││  │ 规则库 (可展开卡片)                  ││
│  │              ││  │ ├── 五行归类规则                    ││
│  │              ││  │ ├── 八卦对应规则                    ││
│  │              ││  │ └── 认知深度分层规则                 ││
│  └──────────────┘│  └───────────────────────────────────┘│
│  (拖拽分隔条)     │                                       │
└──────────────────┴───────────────────────────────────────┘
```

**交互流程**：

```
用户选择节点 → 右侧表单加载节点数据 → 按维度编辑标注
                                        │
                    ┌───────────────────┴───────────────────┐
                    ▼                                       ▼
              保存 (内存)                              应用规则修改
          更新当前标注数据                        更新规则库卡片内容
```

### 4.4 权限控制流程

```
┌──────────┐     ┌──────────────┐     ┌──────────────┐
│  游客模式  │ ──▶ │ 树节点可浏览   │ ──▶ │ 表单字段禁用   │
│ (默认)     │     │ 标注数据可见   │     │ "注册后可编辑" │
└──────────┘     └──────────────┘     └──────────────┘
       │  切换
       ▼
┌──────────┐     ┌──────────────┐     ┌──────────────┐
│ 注册用户   │ ──▶ │ 树节点可浏览   │ ──▶ │ 表单完整可编辑  │
│           │     │ 标注数据可见   │     │ 规则库可修改   │
└──────────┘     └──────────────┘     └──────────────┘
```

当前实现为前端演示模式，权限切换通过页面内按钮模拟。生产环境需对接后端认证服务。

## 5. 数据架构

### 5.1 标注数据模型

每个概念节点的标注数据包含以下 6 个维度：

```json
{
  "id": "c1_1",
  "label": "道可道非常道",
  "desc": "可言说的道不是恒常之道。",
  "wuxing": "水",
  "wuxing_depth": {
    "L1": "水",
    "L2": "水",
    "L3": "土",
    "L4": "水"
  },
  "cognitive_depth": "L2",
  "bagua": "☵坎",
  "source": "道德经·第一章"
}
```

| 维度 | 类型 | 取值范围 | 说明 |
|------|------|----------|------|
| `wuxing` | 枚举 | 金/木/水/火/土 | 五行归类 |
| `wuxing_depth` | 嵌套枚举 | L1-L4 各对应五行值 | 多层五行深度分析 |
| `cognitive_depth` | 枚举 | L1/L2/L3/L4 | 认知深度层级 |
| `bagua` | 枚举 | 乾/兑/离/震/巽/坎/艮/坤 | 八卦归类 |
| `desc` | 文本 | 自由文本 | 概念描述 |
| `source` | 文本 | 自由文本 | 来源出处 |

### 5.2 知识树节点模型

```json
{
  "id": "node_003",
  "name": "预训练策略与架构设计",
  "level": 3,
  "parent_id": "node_002",
  "category": "大语言模型"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 唯一标识 |
| `name` | string | 节点名称 |
| `level` | number | 层级深度（1=根, 2=类, 3=项） |
| `parent_id` | string \| null | 父节点 ID |
| `category` | string | 所属分类 |

### 5.3 规则库数据模型

```json
{
  "id": "rule-wuxing",
  "name": "五行归类规则",
  "description": "具有生长、升发、条达舒畅等作用或性质的事物，均归属于木",
  "preview": "木主生发，火主炎上，土主稼穑，金主从革，水主润下",
  "modification": ""
}
```

## 6. 部署架构

### 6.1 推荐部署方案

```
                   Internet
                       │
                       ▼
              ┌────────────────┐
              │   Nginx :80     │
              │   hui-skill.cn  │
              └───────┬────────┘
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
   pages/         colors_      assets/
   index.html     and_type     (图片/字体)
   annotate.html  .css
```

### 6.2 Nginx 配置

```nginx
server {
    listen 80;
    server_name hui-skill.cn;

    root /var/www/hui-skill-product-matrix;
    index pages/index.html;

    # 静态资源缓存
    location /colors_and_type.css {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    # HTML 不缓存
    location ~ \.html$ {
        add_header Cache-Control "no-cache";
    }

    location / {
        try_files $uri $uri/ =404;
    }
}
```

### 6.3 外部依赖 CDN

| 依赖 | CDN 地址 | 版本 |
|------|----------|------|
| Tailwind CSS | `cdn.jsdelivr.net/npm/@tailwindcss/browser` | 4.3.1 |
| Lucide Icons | `unpkg.com/lucide` | 1.8.0 |

生产环境建议将这两个 CDN 资源下载至本地 `assets/` 目录，避免外部依赖不可用风险。

## 7. 设计工作流

项目使用 Solo Design 工作流进行页面设计与迭代：

```
用户需求 → 车道匹配 → 预检 → 分发清单 → 子代理生成 → 验证 → 就绪
```

关键元数据文件：

| 文件 | 用途 |
|------|------|
| `hui-skill-product-matrix.design` | 设计画布注册表，记录所有页面节点 |
| `runtime-orchestration-summary.json` | 编排总览，记录意图、上下文、验证历史 |
| `runtime-dispatch-manifest.json` | 分发清单，定义页面生成契约 |
| `validation-report.json` | 工作区验证报告 |

### 7.1 新增页面流程

1. 在 `.design` 文件中注册新页面节点
2. 更新 `runtime-orchestration-summary.json` 中的 `pages` 数组
3. 运行 `build-page-dispatch-manifest.mjs` 生成分发清单
4. 分发 Page Sub-Agent 生成 HTML
5. 运行 `apply-html-head-contract.mjs` 统一 head 结构
6. 运行 `validate-design-workspace.mjs` 验证
7. 运行 `validate-finish-readiness.mjs` 就绪检查
